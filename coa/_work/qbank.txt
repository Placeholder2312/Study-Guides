MODULE IV – Memory Systems Organization
CO4
Q1.
Explain the memory hierarchy with a neat diagram. Discuss the characteristics of each level in terms of speed, capacity and cost per bit.
Q2.
Explain the different memory parameters such as access time, memory cycle time, transfer rate and capacity.
Q3.
Classify primary and secondary memories. Explain the characteristics and applications of each.
Q4.
Explain the following types of RAM and ROM:
SRAM
DRAM
PROM
EPROM
EEPROM
Also compare SRAM and DRAM.
Q5.
What is virtual memory? Explain paging and segmentation with suitable diagrams. Compare paging and segmentation.
Q6.
Explain cache memory and its importance in improving processor performance. Explain the L1, L2 and L3 cache hierarchy.
Q7.
A computer has a 32-bit address, a cache of 16 KB, and a cache block size of 16 bytes. For a direct-mapped cache, determine:
a) Number of cache lines
b) Number of bits for block offset
c) Number of bits for cache index
d) Number of bits for tag
Q8.
Explain and compare the following cache mapping techniques with suitable examples:
a) Direct mapping
b) Associative mapping
c) Set-associative mapping
Q9.
A main memory contains 64K blocks, while the cache contains 256 blocks. Each block consists of 8 words. Determine the number of bits required for tag, cache index and word offset using direct mapping.
Q10.
What is cache coherency? Explain the MESI protocol and describe the four states:
Modified
Exclusive
Shared
Invalid

PCI
