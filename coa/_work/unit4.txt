A computer has a memory consisting of 16K memory locations, with each location storing 16 bits.

Number of data lines

C. Memory Hierarchy & Performance
Problem 6 — Average Memory Access Time
A computer has:
L1 cache access time = 2 ns
L2 cache access time = 10 ns
Main memory access time = 100 ns
L1 hit ratio = 90%
L2 hit ratio = 95%
Calculate the average memory access time.
Solution:
Assume sequential lookup.
Probability of:
L1 hit = 0.90
L1 miss = 0.10
L2 hit after L1 miss = 0.10×0.95
Main memory access = 0.10×0.05
Thus:
AMAT=0.92+0.12+10+0.10.05100
=1.8+1.2+0.5
3.5 ns
Problem 7 — Effective Access Time
A cache memory takes 20 ns, while main memory takes 200 ns. The cache hit ratio is 95%.
Calculate the effective memory access time.
Answer:
EAT=0.9520+0.0520+200
=19+11
30 ns

J. Cache Coherency
Cache coherency questions are generally more conceptual, but numerical situations can be created around multiple caches.
Problem 19 — Cache Coherency
Two processors P1and P2have separate caches.
Initially:
X=50
Both caches contain:
X=50
Now:
P1changes Xto 75.
P2reads X.
What value can P2incorrectly obtain if cache coherence is not maintained?
What should P2obtain after applying a coherence protocol?
Answer:
Without coherence:
P2 may read 50
With coherence:
P2 must read 75
This can be extended into a MESI protocol state-transition problem if MESI is included in your detailed syllabus.

Problem 21 — High-Order Interleaving
A memory has 4 banks, each containing 1024 words. Using high-order interleaving, determine the bank number for memory addresses:
500, 1500, 2500, 3500
Solution:
Each bank contains 1024 words.

[TABLE]
Address | Bank
500 | 0
1500 | 1
2500 | 2
3500 | 3
[/TABLE]

Thus:
500→B0
1500→B1
2500→B2
3500→B3
