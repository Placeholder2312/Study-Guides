## Folder structure

```text
dsgt/
├── 00_University_Syllabus/    # Official syllabus extraction and question papers

│   ├── Module_1/
│   ├── Module_2/
│   ├── Module_3/
│   ├── Module_4/
│   ├── Module_5/
│   └── Module_6/
├── 02_Tutorials/              # Tutorial sheets
├── 03_Transcriptions/         # Markdown transcriptions of the lecture material
├── 04_OCR_Reports/            # OCR review and verification reports
├── 05_Study_Guides/           # Working guide sources and exports
├── 06_Revision/               # IAT, prelim and university question banks
├── 07_Unidentified/           # Drafts and material not yet assigned to a module
├── _work/                     # Scratch artefacts (pages, papers, shots, sources, wmf)
├── modules/                   # Published HTML guides
│   ├── module-4.html          # Counting
│   └── module-5.html          # Algebraic Structures
├── AGENTS.md                  # Editing rules for agent sessions
├── index.html                 # Subject landing page
└── README.md                  # This file
```

The numbering matches the Mathematics, BEEE and AOA workspaces, so source material,
transcriptions, OCR reports and guides stay in the same place across subjects.

## Source material

The original lecture PPTs, question-bank archives and extracted images are kept in the
local source library at `C:\Users\Harsh\Downloads\DSGT`, organised into the same
numbered folders. Copyrighted lecture slides and question archives are deliberately
**not committed** here.

## Visual style

Shared Study Guides identity: Georgia headings, Helvetica body, black/white/grey with
the blue accent `#1d4ed8`, square corners, hairline borders, light theme by default and
an optional `sg-theme` dark mode.
