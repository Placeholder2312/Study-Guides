1 — Sets: the vocabulary you must have

Teacher's definitions — Module 1 PPT, slides 4–15

A set is a well-defined collection of distinct objects, written with the members separated by commas and the whole group inside curly brackets { }. The objects in it are its elements or members, and we use lowercase letters for them.

If A = {a, b} then a belongs to A, written a ∈ A, and an element c that is not in A satisfies c ∉ A. The number of elements in a set is its cardinality, written n(A) or |A|. For A = {1, 2, 3, 4}, |A| = 4.

The three dots … are an ellipsis and mean "continue in the same pattern". C = {a, b, c, …, z} has 26 elements.

Simple meaning. A set is a bag with no order and no duplicates. {2, 4, 6} and {6, 2, 4} and {2, 4, 4, 6} are all the same set. The order of writing carries no information, and repeating an element changes nothing.

Formal definition — subset

A is a subset of B, written A ⊆ B, when every element of A is also an element of B. In symbols:

A ⊆ B ⟺ ∀x (x ∈ A → x ∈ B)

A is a proper subset of B, written A ⊂ B, when A ⊆ B and there is at least one element of B that is not in A. Two sets are equal when A ⊆ B and B ⊆ A.

That single line does most of the work in this module. "Subset" is a quantified implication, so it is proved like one and negated like one. To show A ⊄ B you must produce one element that is in A and not in B.

Facts worth memorising. They are asked as fill-in-the-blank and used silently in proofs.

  1. ∅ ⊆ A for every set A, including A = ∅. The empty set is a subset of everything.
  2. A ⊆ A for every set A. Every set is a subset of itself.
  3. If A ⊆ B and B ⊆ C then A ⊆ C. Subset is transitive.
  4. ∅ is a member of {∅}, but ∅ is not a member of ∅. The empty set contains nothing at all.
  5. If |A| = n then A has 2n subsets. This is the power-set count.

Power set

Definition — asked verbatim in the IAT sample and the prelim bank

The power set of A, written P(A), is the set of all subsets of A:

P(A) = { X | X ⊆ A }

Every element of P(A) is itself a set. If |A| = n then |P(A)| = 2n.

How to recognise the question. "Write the power set of A", "find P(A) and its cardinality", "how many subsets does A have". They are the same task. The trap is always the two sets people forget: ∅ and A itself.

Worked example — the power set of a three-element set
Question

Find the power set P(A) and its cardinality for A = {a, b, c}.

Solution

A = {a, b, c}, so |A| = 3 and P(A) must have 23 = 8 members. Build them by size, which guarantees nothing is missed or repeated:

0 elements: ∅

1 element: {a}, {b}, {c}

2 elements: {a, b}, {a, c}, {b, c}

3 elements: {a, b, c}

Each of the eight is a subset of A, and each is written as a set inside the outer brackets. Count: 1 + 3 + 3 + 1 = 8. ✓

Exam presentation. Write the count 23 = 8 first, group the subsets by size, then present the final set. The grouping is what shows the examiner you checked.

Final Answer
P(A) = { ∅, {a}, {b}, {c}, {a,b}, {a,c}, {b,c}, {a,b,c} }
Worked example — the two edge cases that get asked
Question

Find the power sets and cardinalities of A = ∅ and A = {∅}. Explain the difference between ∅ and {∅}.

Solution

For A = ∅: the only subset of ∅ is ∅ itself, so P(∅) = {∅} and |P(∅)| = 20 = 1. Note that ∅ ≠ {∅}: the left has no elements, the right has one.

For A = {∅}: its subsets are ∅ and {∅}, so P({∅}) = {∅, {∅}} and |P({∅})| = 2. The pattern continues: |P(P(∅))| = 21 = 2, and so on.

Final Answer

P(∅) = {∅} and |P(∅)| = 1. P({∅}) = {∅, {∅}} and |P({∅})| = 2.

Common mistakes

  • Writing a ∈ A when you mean {a} ⊆ A. A single element and a one-element set are different objects.
  • Using ⊂ when the sets are equal. {1,2} ⊂ {1,2} is false; {1,2} ⊆ {1,2} is true.
  • Leaving ∅ out of the power set, or leaving out A itself. That gives 2n − 2 subsets instead of 2n.
  • Saying |∅| = 1. The empty set has zero elements; {∅} has one.
  • Confusing "equivalent sets" (same cardinality, different elements allowed) with "equal sets" (identical elements). {1,2} and {p,q} are equivalent but not equal.
  • Writing a set as {a, b, a} and calling its cardinality 3. Duplicates collapse, so the answer is 2.

Quick check 1

(a) Write P({a, b, c, d}) and give its cardinality. (IAT sample Q10.)
(b) True or false, with one line of reason each: (i) ∅ ∈ {∅}; (ii) ∅ ⊆ {∅}; (iii) {∅} ⊆ ∅; (iv) {1, 2} ⊂ {1, 2, 3}.
(c) Write the set of even integers between 1 and 11 in roster form and in set-builder form. (Answer Q1.)

2 — Set operations and the laws of sets

Teacher's definitions — Module 1 PPT, slides 18–19

Union A ∪ B lists every element that is in A, in B, or in both. Intersection A ∩ B lists the common elements. Difference A − B lists the elements of A that are not in B. Complement A′ lists the elements of the universal set that are not in A. Symmetric difference A △ B lists the elements that are in exactly one of A and B:

A △ B = (A ∪ B) − (A ∩ B) = (A − B) ∪ (B − A)

With U = {1, 2, …, 10} and A = {2, 3, 4, 5, 6} the complement is A′ = {1, 7, 8, 9, 10}. The complement is the one operation that cannot be computed without knowing U, so copy U down before you start.

Two words the question bank uses. A and B are disjoint when A ∩ B = ∅ — they share nothing. They are overlapping when A ∩ B ≠ ∅. Disjointness is a statement about the intersection, not about the elements individually.

Checking a law: membership tables

A membership table is the set-theory version of a truth table. It records, for each possible combination of "x is in A", "x is in B", whether x is in each expression. Write 1 for "in" and 0 for "not in". Two expressions are equal exactly when their columns match in every row.

Worked example — the same law checked numerically
Question

For U = {1, 2, …, 10}, A = {2, 3, 4, 5, 6} and B = {5, 6, 7}, verify that (A ∪ B)′ = A′ ∩ B′.

Solution

A ∪ B = {2, 3, 4, 5, 6, 7}, so (A ∪ B)′ = {1, 8, 9, 10}.

Same set. A single numerical check never proves a law, but it catches almost every algebra slip, and it is a cheap way to earn the last mark on a "verify" question.

Final Answer

(A ∪ B)′ = A′ ∩ B′ = {1, 8, 9, 10}. This numerical example verifies the identity for these sets; it is not a general proof.

Common mistakes

  • Treating A − B and B − A as the same. {1,2} − {3,4,5,6} and {3,4,5,6} − {1,2} are different sets, and one of them may be empty.
  • Writing A − B as A′ − B or as A ∩ B. The correct identity is A − B = A ∩ B′.
  • Computing a complement with no universal set stated. If U is not given, say what you are assuming.
  • Reading A △ B as "everything except B". It is the elements in exactly one of the two sets, so the common elements are removed.
  • Quoting distributivity in the wrong direction and then "simplifying" into a longer expression.
  • Forgetting that ∪ and ∩ are commutative but − is not.

3 — Cartesian product and partitions

Definition — ordered pair and Cartesian product

An ordered pair (a, b) is determined by its two coordinates in order: (a, b) = (c, d) exactly when a = c and b = d. The Cartesian product of A and B is the set of all ordered pairs with first coordinate from A and second from B:

A × B = { (a, b) | a ∈ A and b ∈ B }

If |A| = m and |B| = n then |A × B| = mn.

Simple meaning. Pick one item from the first set, pair it with one item from the second, and do that for every combination. The pair is written with round brackets because order matters inside it.

Properties that get examined.

  1. A × B and B × A have the same number of elements but are not the same set, unless A = B. (1, 3) is in {1,3,5} × {2,3,8} but (3, 1) is in the other product.
  2. A × ∅ = ∅ for every A, because there is no second coordinate to choose.
  3. The product distributes over union and intersection: A × (B ∪ C) = (A × B) ∪ (A × C), and the same with ∩.
  4. A relation from A to B is by definition a subset of A × B, so |A × B| is the number of possible ordered pairs a relation could contain.
  5. |P(A × B)| = 2|A||B|, the number of relations from A to B.

Partitions

Definition — partition of a set

A partition of a non-empty set A is a collection of non-empty subsets of A, called blocks, such that

(i) the blocks are pairwise disjoint: no element belongs to two of them; and
(ii) their union is all of A.

In symbols, if the blocks are B1, …, Bk then Bi ∩ Bj = ∅ for i ≠ j, and B1 ∪ … ∪ Bk = A.

Two conditions, both required. Missing blocks leave elements unaccounted for; overlapping blocks put an element in two places. Either failure means it is not a partition.

One block: { {1, 2, 3} }

Why partitions matter. The equivalence classes of an equivalence relation always form a partition of the set, and every partition comes from exactly one equivalence relation. If Module 2 asks you to "find the equivalence classes and verify they partition A", this is the definition you are checking against.

Common mistakes

  • Writing |A × B| = |A| + |B|. It is a product: three choices times three choices gives nine pairs.
  • Using curly brackets for an ordered pair, as in {1, 2} ∈ A × B. Curly brackets destroy the order, so (1, 2) and (2, 1) collapse into one object.
  • Assuming A × B = B × A. They are equal only when A = B, or when one of them is empty.
  • Forgetting that ∅ is never a block of a partition, because blocks must be non-empty.
  • Listing the subsets of A and calling them a partition. The collection must cover A without overlaps, not merely consist of subsets.

Three methods prove a claimed identity A = B. Use whichever the question hints at; if it does not hint, the element argument is always acceptable and the algebraic one is fastest.

Worked example — element argument for A − B = A ∩ B′
Question

Prove the set identity A − B = A ∩ B′ using an arbitrary element.

Solution

Let x be an arbitrary element of U. Then

x ∈ A − B ⟺ x ∈ A and x ∉ B    (definition of set difference) ⟺ x ∈ A and x ∈ B′    (definition of complement) ⟺ x ∈ A ∩ B′    (definition of intersection)

Exam presentation. Start with "Let x be arbitrary", chain the equivalences with ⟺ (not →), and finish with "since x was arbitrary, A − B = A ∩ B′". The last sentence is part of the proof.

Final Answer

Each step is an equivalence, so the two sets contain exactly the same elements and are equal. ∎

Common mistakes

  • Proving only A ⊆ B and stopping. Equality needs both inclusions, or a chain of ⟺.
  • Using ⟹ in a chain of equivalences. If you only have one direction, you have only proved a subset relation.
  • Starting from the statement you are asked to prove and manipulating both sides at once without saying so. Work down from one side.
  • Naming no laws in an algebraic proof. Unnamed steps are assertions, and examiners deduct for them.
  • Building the membership table with the wrong number of rows. n sets need 2n rows, so three sets need eight.
  • Reading a Venn diagram and calling it a proof. A picture illustrates; it does not prove.

5 — Propositional logic and truth tables

Teacher's definitions — Module 1 PPT, slides 29–39

A proposition is a declarative sentence that is either true or false, but not both. "Delhi is the capital of India" is a proposition. "Sit down!" is not, because a command has no truth value. "x + 1 = 2" is not, because it is true or false only after x is fixed.

A compound proposition is built from simpler ones using the logical connectives: negation ¬, conjunction ∧, disjunction ∨, implication → and biconditional ↔. The simple statements inside it are atomic propositions, written with variables p, q, r, …

Simple meaning. Logic is arithmetic on truth values. Two values, T and F; five operations; and a fixed rule for each combination. Everything else in this module is bookkeeping over those rules.

Four rows, because two variables give 22 = 4 combinations. With three variables it is 8 rows, and with n variables 2n. Always use the same row order — TT, TF, FT, FF downwards — so the marker can compare your table with the expected one.

The five connectives, in words.

  1. ¬p flips the value. It is the only unary connective.
  2. p ∧ q is true only when both are true. Read "and".
  3. p ∨ q is true when at least one is true. This is the inclusive or, which is what mathematics always means by "or".
  4. p ⊕ q is exclusive or: true when exactly one is true. "One or the other but not both."
  5. p → q is false in exactly one case: p true and q false. Every other row is true.

Implication is the one that trips everyone up. From a false hypothesis, anything follows. "If 1 + 1 = 3, then your grandmother wears combat boots" is a true implication, because the hypothesis is false. The connective records only the truth-value relationship; it does not claim that p causes q, and it does not require the two statements to be about the same subject.

"p only if q" is the classic trap: it translates to p → q, not q → p. Test it with a sentence. "You will pass only if you write the exam" means passing forces writing; it does not mean writing forces passing.

Converse, inverse, contrapositive

From p → q you can build three related statements. Only one of them is equivalent to the original.

NameFormEquivalent to p → q?
Converseq → pNo
Inverse¬p → ¬qNo
Contrapositive¬q → ¬pYes

The converse and the inverse are equivalent to each other, and both fail to be equivalent to the original. You will prove this in section 6 with a truth table, which is a standard exam question.

Precedence. When brackets are missing, ¬ binds tightest, then ∧, then ∨, then →, then ↔. So p ∨ q → ¬r means (p ∨ q) → ¬r. Do not rely on this in your answers: bracket everything you write.

Worked example — translating an English sentence (teacher's slide 53)
Question

"You can access the Internet from campus only if you are a computer science major or you are not a freshman."

Solution

Step 1 — name the atoms. p: you can access the Internet from campus. q: you are a computer science major. r: you are a freshman.

Step 2 — find the main connective. "only if" attaches the whole first clause to the whole second clause, so p is the hypothesis and everything after "only if" is the conclusion.

Step 3 — build the conclusion. "a computer science major or not a freshman" is q ∨ ¬r.

Check with a row. Suppose you are not a CS major and you are a freshman, so q = F and r = T. Then q ∨ ¬r = F, so the implication is false when p is true: you cannot access the system. That matches the English.

Final Answer
p → (q ∨ ¬r)

Common mistakes

  • Making p → q false when p is false. A false hypothesis makes the implication true.
  • Translating "p only if q" as q → p. It is p → q.
  • Reading ∨ as exclusive or. p ∨ q is true when both are true; ⊕ is the exclusive version.
  • Writing too few rows. Three atoms need eight rows, not six and not four.
  • Treating the converse as equivalent to the original. "All dogs are animals" is true; "all animals are dogs" is its converse and false.
  • Putting the negation in the wrong place in the sub-column, for example writing ¬(p ∨ q) where the expression says (¬p) ∨ q.

6 — Logical equivalence

Teacher's definition — Module 1 PPT, slides 46–47

Two propositions are logically equivalent, written A ≡ B, when they always have the same truth value. Equivalently, A ≡ B exactly when the biconditional A ↔ B is a tautology. An identity that is true for every assignment of truth values is called a law of logic.

Two ways to prove it, and how to choose. A truth table proves equivalence by exhaustion: fill in every row and show the two columns match. A chain of laws proves it by derivation: rewrite one side until it looks like the other. Use the table when the expression has at most three atoms and the question says "using truth tables"; use the laws when the question says "using logical equivalences", which the university papers usually do. The derivation is faster and shorter, but every step must be justified.

Dominationp ∨ T ≡ T    p ∧ F ≡ F
Idempotentp ∨ p ≡ p    p ∧ p ≡ p
Double negation¬(¬p) ≡ p
Commutativep ∨ q ≡ q ∨ p    p ∧ q ≡ q ∧ p
Associative(p ∨ q) ∨ r ≡ p ∨ (q ∨ r)    same with ∧
Distributivep ∧ (q ∨ r) ≡ (p ∧ q) ∨ (p ∧ r)    p ∨ (q ∧ r) ≡ (p ∨ q) ∧ (p ∨ r)

Almost every equivalence question in this module starts with the implication law. Whenever you see → and the target has no →, convert every arrow with p → q ≡ ¬p ∨ q as the first move.

Exam question
Summer 2026, Q.1(b), 5 marks

Using a series of logical equivalences, prove that ((p → q) → r) and (p ∧ ¬q) ∨ r are logically equivalent. Interpret how logical equivalence helps simplify decision rules in software systems.

Worked example — the Summer 2026 proof

Work downwards from the left-hand expression, one law per line.

(p → q) → r
≡ ¬(p → q) ∨ r    (implication law applied to the outer arrow)
≡ ¬(¬p ∨ q) ∨ r    (implication law applied to p → q)
≡ (p ∧ ¬q) ∨ r    (De Morgan, then double negation)

That is the right-hand expression, so the two are logically equivalent. ∎

Truth-table confirmation. The derivation is the answer, but the table below shows the claim really holds in every row — useful if you have time to add a check.

The interpretation part. The two forms describe the same decision rule, but the right-hand one contains no implication. In a program, (p ∧ ¬q) ∨ r is three basic tests joined by AND, NOT and OR — a direct branch — whereas nested implications are harder to read and harder to test. Equivalence lets a designer replace a convoluted rule with a simpler one without changing any outcome, which is what makes automated rules engines and access-control checks auditable.

Exam presentation. One expression per line, law named at the right, final line matching the target exactly. Then a two- or three-sentence interpretation. The marks are split roughly three for the derivation and two for the interpretation.

Exam question
Winter 2025, Q.1(b)

Prove that (P ∨ Q) → R ≡ (P → R) ∧ (Q → R).

Worked example — the Winter 2025 proof

Reduce both sides separately until they meet in the middle. This is easier than pushing one side all the way, because each side needs only two steps.

Left-hand side.

(P ∨ Q) → R
≡ ¬(P ∨ Q) ∨ R    (implication law)
≡ (¬P ∧ ¬Q) ∨ R    (De Morgan)

Right-hand side.

(P → R) ∧ (Q → R)
≡ (¬P ∨ R) ∧ (¬Q ∨ R)    (implication law, twice)
≡ (¬P ∧ ¬Q) ∨ R    (distributive law, read right to left)

Both sides equal (¬P ∧ ¬Q) ∨ R, so they are equivalent. ∎

Why the last step is legitimate. Distributivity says X ∨ (Y ∧ Z) ≡ (X ∨ Y) ∧ (X ∨ Z). Put X = R, Y = ¬P, Z = ¬Q and read it from right to left: (¬P ∨ R) ∧ (¬Q ∨ R) ≡ R ∨ (¬P ∧ ¬Q). The ∧ terms are swapped by the commutative law for good measure, and that is the left-hand result.

The dual worth knowing. The same argument with ∧ and ∨ exchanged gives (P ∧ Q) → R ≡ (P → R) ∨ (Q → R). Both identities are true, and mixing them up is a common error. "If either one happens, then R" splits into an AND of implications; "if both happen, then R" splits into an OR.

Worked example — a third equivalence (IAT sample Q11(i))

Prove that ¬(p ∨ (¬p ∧ q)) ≡ ¬p ∧ ¬q.

¬(p ∨ (¬p ∧ q))
≡ ¬p ∧ ¬(¬p ∧ q)    (De Morgan)
≡ ¬p ∧ (p ∨ ¬q)    (De Morgan again, then double negation)
≡ (¬p ∧ p) ∨ (¬p ∧ ¬q)    (distributive law)
≡ F ∨ (¬p ∧ ¬q)    (complementation: ¬p ∧ p ≡ F)
≡ ¬p ∧ ¬q    (identity law)

Five steps, five laws. If the question allows only a truth table, this same expression takes four rows; either is accepted, but the derivation is what the phrase "using logical equivalences" asks for.

Common mistakes

  • Applying De Morgan to an implication: writing ¬(p → q) as ¬p → ¬q. It is p ∧ ¬q.
  • Dropping a negation in the middle of a chain, especially after two De Morgan steps.
  • Claiming equivalence because the two expressions agree in most rows. They must agree in all 2n rows.
  • Using ⇔ or ⟺ between expressions without saying that is what you are proving. In a derivation chain use ≡, which means "equivalent to".
  • Changing both sides at once and losing track of which statement you have actually established.
  • Naming a law that does not apply — "by De Morgan" on a step that needs distributivity.
  • Answering only the derivation in a question that also says "interpret". That second part carries marks.

Quick check 6

(a) Prove p → q ≡ ¬q → ¬p using the laws of logic.
(b) Prove ¬(p ∧ q) ∨ p ≡ p ∨ ¬q.
(c) Show that the converse of p → q is not equivalent to p → q, by giving one row of a truth table where they differ. (Answer Q6.)

7 — Tautology, contradiction, contingency — and CNF/DNF

Teacher's definitions — Module 1 PPT, slides 55–56

A tautology is a compound proposition that is true for every assignment of truth values — for example p ∨ ¬p. A contradiction is false for every assignment — for example p ∧ ¬p. A contingency is neither: true in some rows and false in others, such as ¬p.

TypeFinal column of the truth tableHow to answer "classify this"
TautologyAll TSay "tautology" and show the column is all T
ContradictionAll FSay "contradiction" and show the column is all F
ContingencyMixedSay "contingency" and give one T row and one F row

Two routes to the answer. The truth table always works and is what most questions intend. Simplification with the laws is faster and shows more understanding, and it is the only practical route once there are four or more atoms. Do the table if the expression has at most three atoms; simplify if it has more, or if you can already see the shape.

Worked example — is [(p → r) ∧ (¬q → p) ∧ ¬r] → q a tautology? (IAT sample Q9(i))

Simplify the antecedent first, because it contains a fact that kills one of its own parts.

The antecedent.

(p → r) ∧ ¬r
≡ (¬p ∨ r) ∧ ¬r    (implication law)
≡ (¬p ∧ ¬r) ∨ (r ∧ ¬r)    (distributive law)
≡ (¬p ∧ ¬r) ∨ F    (complementation)
≡ ¬p ∧ ¬r    (identity law)

So the antecedent gives us both ¬p and ¬r. Now the middle conjunct:

(¬q → p) ≡ q ∨ p    (implication law, with the double negation simplified)

Combine. The whole antecedent is (¬p ∧ ¬r) ∧ (q ∨ p). Since ¬p holds, p is false, so q ∨ p reduces to q:

(¬p ∧ ¬r) ∧ (q ∨ p) ≡ (¬p ∧ ¬r) ∧ q    (p is false, so q ∨ p ≡ q)

The implication. Let A = ¬p ∧ ¬r ∧ q. We must classify A → q:

A → q ≡ ¬A ∨ q ≡ ¬(¬p ∧ ¬r ∧ q) ∨ q

But A already contains q as a conjunct, so whenever A is true, q is true. Formally:

(¬p ∧ ¬r ∧ q) → q ≡ ¬(¬p ∧ ¬r ∧ q) ∨ q ≡ (p ∨ r ∨ ¬q) ∨ q ≡ p ∨ r ∨ (¬q ∨ q) ≡ p ∨ r ∨ T ≡ T

Every assignment makes it true, so it is a tautology.

Faster reading. The antecedent asserts ¬r and also that p → r. If p were true, r would be true, contradicting ¬r. So p is false. With p false, ¬q → p forces ¬q to be false, that is q is true. So the antecedent can only be true when q is true, which is exactly what the implication claims. That argument is the same simplification in words, and it is what you should write if the question says "justify".

Worked example — is (p → q) ∧ ¬q a tautology? (IAT sample Q9(ii))

(p → q) ∧ ¬q
≡ (¬p ∨ q) ∧ ¬q    (implication law)
≡ (¬p ∧ ¬q) ∨ (q ∧ ¬q)    (distributive law)
≡ (¬p ∧ ¬q) ∨ F    (complementation)
≡ ¬p ∧ ¬q    (identity law)

This is true when p and q are both false, and false otherwise. It is a contingency, not a tautology.

Notice what the expression means: "p implies q, and q is false". The only way that can hold is p false as well. It is the first half of modus tollens — the step that concludes ¬p. The implication (p → q) ∧ ¬q → ¬p is a tautology, and that is the inference rule; strip the conclusion and you get a contingency.

Worked example — (p → q) ↔ (¬q → ¬p) is a tautology

By the contrapositive law, p → q ≡ ¬q → ¬p. So the two sides of the biconditional are the same proposition, and X ↔ X ≡ T. That is a one-line proof if the law is allowed.

By truth table: columns for p → q and ¬q → ¬p are both F, T, T, T, so the biconditional column is T, T, T, T. Both routes give the same verdict, and the table is what to write if the question says "using truth tables".

CNF and DNF

Both university question banks ask for CNF or DNF, so learn the vocabulary precisely. It is easy marks once the names are straight.

TermMeaningExample
LiteralA variable or its negationp, ¬q
ClauseLiterals joined by ∨p ∨ ¬q ∨ r
Term (minterm)Literals joined by ∧, one per variablep ∧ ¬q ∧ r
CNFConjunction of clauses — AND of ORs(p ∨ q) ∧ (¬p ∨ r)
DNFDisjunction of terms — OR of ANDs(p ∧ q) ∨ (¬p ∧ r)

The names tell you the outer operator: CNF has the conjunction outside; DNF has the disjunction outside. If you remember only that, you will not swap them.

  1. Remove every ↔ using p ↔ q ≡ (p → q) ∧ (q → p).
  2. Remove every → using p → q ≡ ¬p ∨ q.
  3. Push negations inwards with De Morgan and double negation until ¬ sits only on single variables.
  4. For CNF, distribute ∨ over ∧ until the expression is an AND of ORs. For DNF, distribute ∧ over ∨ until it is an OR of ANDs.
  5. Drop duplicate literals and duplicate clauses, and delete clauses containing q ∨ ¬q (they are T, so they vanish from a conjunction).
Worked example — CNF and DNF of [P → (Q ∧ R)] ∧ [¬P → (¬Q ∧ ¬R)] (IAT sample Q9(ii))

Step 2 — remove the arrows.

P → (Q ∧ R) ≡ ¬P ∨ (Q ∧ R)

¬P → (¬Q ∧ ¬R) ≡ ¬(¬P) ∨ (¬Q ∧ ¬R) ≡ P ∨ (¬Q ∧ ¬R)

Step 3 — negations are already on single variables. Nothing to do.

Step 4 — distribute for CNF.

¬P ∨ (Q ∧ R) ≡ (¬P ∨ Q) ∧ (¬P ∨ R)

P ∨ (¬Q ∧ ¬R) ≡ (P ∨ ¬Q) ∧ (P ∨ ¬R)

CNF: (¬P ∨ Q) ∧ (¬P ∨ R) ∧ (P ∨ ¬Q) ∧ (P ∨ ¬R)

Four clauses, each a disjunction, joined by ∧.

For the DNF, use the truth table. Distributing the four clauses into an OR of ANDs is long and error-prone; reading the true rows is reliable.

Only rows 1 and 8 are true, so the DNF has exactly two terms — one matching each true row, with a letter negated where that row has F:

Sanity check on the CNF: set P = F, Q = F, R = F. Clause 1 is ¬F ∨ F = T; clause 2 is ¬F ∨ F = T; clause 3 is F ∨ ¬F = T; clause 4 is F ∨ ¬F = T. All four true, so the conjunction is true — and row 8 of the table is indeed 1. Now set P = F, Q = T, R = F: clause 1 is T, clause 2 is T, clause 3 is F ∨ F = F. The conjunction is false, matching row 6. The CNF is right.

Exam presentation. State which one you are producing, show the arrow-removal steps, then the distribution. Write the final answer on its own line, with the outer operator obvious. If you use the truth table for the DNF, say so — "reading the true rows" is a legitimate method and examiners accept it.

A note on one bank question

The banks also print "Convert into CNF and DNF: (A → B) → (B → C) → (A → C)". As printed the brackets are ambiguous. Under either sensible reading — [(A → B) ∧ (B → C)] → (A → C), or (A → B) → ((B → C) → (A → C)) — the statement is a tautology (it is hypothetical syllogism), so its CNF is simply true and its DNF is the disjunction of all eight minterms. That is a legitimate answer but a strange exam question, so state your reading, prove the tautology in two lines, and add the two forms. If your teacher intended a different grouping, the method above still applies; only the arithmetic changes.

Common mistakes

  • Swapping CNF and DNF. Check which operator is on the outside.
  • Stopping the distribution halfway, leaving a ∧ inside a clause or a ∨ inside a term.
  • Leaving a negation over a bracket, as in ¬(P ∨ Q), instead of pushing it in with De Morgan.
  • Converting → to ∧. The implication law uses ∨: p → q ≡ ¬p ∨ q.
  • Calling a contingency a tautology because most rows are true. One false row is enough to disqualify it.
  • Writing the final column of the truth table from the wrong sub-column, usually by reading ¬r as ¬q.
  • Forgetting to drop repeated clauses, so the answer has (¬P ∨ Q) twice.

8 — Predicates and quantifiers

Teacher's definitions — Module 1 PPT, slides 70–82

A predicate (or propositional function) is a statement containing one or more variables, whose truth depends on the values those variables take. "x is greater than 3" is a predicate; we write it P(x). P is the predicate symbol and x is its argument.

A predicate becomes a proposition — something with a truth value — in exactly two ways: replace every variable by a value from the domain, or bind every variable with a quantifier. The set of allowed values is the domain or universe of discourse, usually written U.

PredicateRead asName
Father(x)x is a fatherunary (one argument)
Brother(x, y)x is a brother of ybinary
Sum(x, y, z)x + y = zternary
P(x1, …, xn)an n-place propertyn-ary

With P(x) meaning "x > 5" and U the integers, P(8) is true and P(5) is false. With P(x, y, z) meaning x + y = z, P(−4, 6, 2) is true and P(5, 2, 10) is false. But P(5, x, 7) is still a predicate, not a proposition, because x is free.

QuantifierSymbolRead asTrue when
Universal∀x P(x)for all x, P(x)every element of U satisfies P
Existential∃x P(x)there exists x such that P(x)at least one element of U satisfies P

The domain decides the truth value, not just the predicate. Let P(x) be "x > 0". With U = the integers, ∀x P(x) is false. With U = the positive integers, ∀x P(x) is true. Nothing about P changed; only the universe did. So every answer must state the domain.

Finite domains turn quantifiers into connectives. If U = {1, 2, 3} then

∀x P(x) ≡ P(1) ∧ P(2) ∧ P(3)     ∃x P(x) ≡ P(1) ∨ P(2) ∨ P(3)

That is why the translation rules below use ∧ with ∃ and → with ∀.

Translating English into quantifiers

English shapeSymbolic formNote
All S are P∀x (S(x) → P(x))implication, never ∧
Some S are P∃x (S(x) ∧ P(x))conjunction, never →
No S are P∀x (S(x) → ¬P(x))same as "all S are not P"
Some S are not P∃x (S(x) ∧ ¬P(x))the negation of "all S are P"

Getting ∧ and → the wrong way round is the single most common error in this topic, and it is easy to see why it is wrong. "All students are friendly" as ∀x(S(x) ∧ F(x)) claims that everything in the universe is a student and friendly — including the examiner's dog. The implication version says: if it is a student, then it is friendly, which is what the English means.

Negating a quantified statement

The two negation rules
¬∀x P(x) ≡ ∃x ¬P(x)      ¬∃x P(x) ≡ ∀x ¬P(x)

To negate a quantifier, flip it and negate the inside. "Not all" becomes "some not"; "none" becomes "all not".

Worked example — the Java sentence and its negation (teacher's slide 86)

"Every student in this class has taken a course in Java." Domain: all people.

Predicates: Student(x) — x is a student in this class; Taken(x, y) — x has taken course y; Java is a constant naming the Java course.

∀x (Student(x) → Taken(x, Java))

Negation. Flip the quantifier swap to ∃, then negate the implication:

¬∀x (Student(x) → Taken(x, Java))
≡ ∃x ¬(Student(x) → Taken(x, Java))    (negation rule)
≡ ∃x (Student(x) ∧ ¬Taken(x, Java))    (negation of implication)

In words: there is at least one student in this class who has not taken Java. That is exactly the English negation. Note that the ∧ appears here for a reason — the ¬ before the implication is what turns → into ∧.

Worked example — two sentences from the prelim bank

Domain: all people. S(x): x is a student. G(x): x took GenAI. P(x): x passes GenAI.

(i) Some students took GenAI. The word "some" needs ∃ and the two conditions are both asserted, so they join with ∧:

∃x (S(x) ∧ G(x))

(ii) Every student who takes GenAI passes it. "Every … who" makes the student-and-GenAI part a hypothesis, so it becomes the left side of an implication:

∀x ((S(x) ∧ G(x)) → P(x))

The ∧ sits inside the hypothesis because "student who takes GenAI" is one combined condition; the → separates it from the conclusion.

Worked example — three class statements (teacher's slide 87)

S(x): x is a student. M(x): x has taken a course in mathematics. G(x): x is a girl student. C(x): x is in the class. P(x): x is a sports person. I(x): x is intelligent. H(x): x is hardworking.

(i) All students have taken a course in mathematics.

∀x (S(x) → M(x))

(ii) There is a girl student in a class who is also a sports person. Three conditions must hold of the same person, so all three join with ∧:

∃x (G(x) ∧ C(x) ∧ P(x))

(iii) Some students are intelligent, but not hardworking. "But" means "and".

∃x (S(x) ∧ I(x) ∧ ¬H(x))

Two quantifiers in one statement

When quantifiers are nested, order matters. Compare, over the real numbers:

∀x ∃y (x + y = 0) — for every x there is some y, namely y = −x. True.

∃y ∀x (x + y = 0) — there is one fixed y that works for every x. False.

Read left to right: the first quantifier chooses first, and later ones may depend on it. A y chosen after x can depend on x; a y chosen before x cannot.

Common mistakes

  • Writing ∀x (S(x) ∧ P(x)) for "all S are P". Use →.
  • Writing ∃x (S(x) → P(x)) for "some S is P". Use ∧.
  • Negating ∀x P(x) as ∀x ¬P(x). That is the negation of ∃x P(x).
  • Negating a quantified implication without turning the → into ∧. ¬(A → B) is A ∧ ¬B.
  • Leaving the domain unstated, then arguing about the truth value.
  • Swapping nested quantifiers and expecting the same meaning.
  • Treating a predicate with a free variable as a proposition.

10 — Mathematical induction

Teacher's definition — Module 1 PPT, slide 101; the exam question is Summer 2026 Q.4(b)

Principle of mathematical induction. Let P(n) be a statement about the natural numbers. If

(i) P(1) is true — the base case, and
(ii) for every k ≥ 1, P(k) true implies P(k+1) true — the inductive step,

then P(n) is true for every n ≥ 1.

Why it works. The base case starts a chain. The inductive step says each true statement forces the next one. So P(1) forces P(2), P(2) forces P(3), and so on without end. Induction is not "assuming what you want to prove": you assume P(k) for one unspecified k and prove P(k+1) from it, which is a conditional statement.

  1. State P(n) explicitly. Write the claim with n in both sides so the target is unambiguous.
  2. Base case. Substitute the starting value, compute both sides separately, and say they are equal.
  3. Inductive hypothesis. "Assume P(k) is true for some arbitrary k ≥ 1", and write that equation down. You will use it.
  4. Inductive step. Show P(k+1). Start from the left side at k+1, split off the new last term, replace the rest using the hypothesis, then algebraically reach the right side at k+1. Finish with "this is P(k+1)".
  5. Conclusion. "By the principle of mathematical induction, P(n) holds for all n ≥ 1."
Exam question
Summer 2026, Q.4(b), 7 marks

Using the principle of mathematical induction, prove that for every positive integer n,

Σr=1n r(r + 3) = n(n + 1)(n + 5) / 3
Worked example — the Summer 2026 induction: claim, base and hypothesis

Claim. P(n): Σr=1n r(r + 3) = n(n + 1)(n + 5)/3 for all n ≥ 1.

Base case, n = 1. The left side has one term, 1·(1 + 3) = 4. The right side is 1·2·6/3 = 4. Both are 4, so P(1) is true. ✓

Inductive hypothesis. Assume P(k) is true for some arbitrary k ≥ 1:

Σr=1k r(r + 3) = k(k + 1)(k + 5) / 3
Worked example — the Summer 2026 induction: the step and the conclusion

Inductive step. We must prove P(k+1), that is Σr=1k+1 r(r + 3) = (k+1)(k+2)(k+6)/3. Start from the left and split off the term r = k+1:

Σr=1k+1 r(r + 3)
= Σr=1k r(r + 3) + (k + 1)(k + 4)

Now use the hypothesis on the sum:

= k(k + 1)(k + 5)/3 + (k + 1)(k + 4)

Take out the common factor (k+1):

= (k + 1) [ k(k + 5)/3 + (k + 4) ]

Put the bracket over the single denominator 3, using (k + 4) = 3(k + 4)/3:

= (k + 1) [ (k² + 5k + 3k + 12) / 3 ]
= (k + 1)(k² + 8k + 12)/3

Factor the quadratic: k² + 8k + 12 = (k + 2)(k + 6), since 2 + 6 = 8 and 2·6 = 12.

= (k + 1)(k + 2)(k + 6)/3

Now check this is the right side at k+1. Replacing k by k+1 in n(n+1)(n+5)/3 gives (k+1)(k+2)((k+1)+5)/3 = (k+1)(k+2)(k+6)/3. It matches. ∎

Conclusion. P(1) is true and P(k) implies P(k+1) for arbitrary k ≥ 1. By the principle of mathematical induction, P(n) is true for all n ≥ 1.

Numerical check. At n = 3 the left side is 1·4 + 2·5 + 3·6 = 4 + 10 + 18 = 32, and the right side is 3·4·8/3 = 32. ✓ At n = 4 the left side gains 4·7 = 28, giving 60, and the right side is 4·5·9/3 = 60. ✓ Checks against the closed form are a good way to catch a wrong factor at (k+2)(k+6).

Exam presentation. Six labelled blocks: claim, base, hypothesis, step, "which is P(k+1)", conclusion. The marks are distributed across the blocks, so a correct algebra with no conclusion still loses a mark.

Worked example — the teacher's arithmetic series (slides 103–105)

Prove by induction that 1 + 5 + 9 + … + (4n − 3) = n(2n − 1) for all n ≥ 1.

Base, n = 1. Left: the single term is 4(1) − 3 = 1. Right: 1·(2 − 1) = 1. ✓

Hypothesis. Assume 1 + 5 + … + (4k − 3) = k(2k − 1).

Step. Add the term for n = k+1, which is 4(k+1) − 3 = 4k + 1:

1 + 5 + … + (4k − 3) + (4k + 1)
= k(2k − 1) + (4k + 1)    (by the hypothesis)
= 2k² − k + 4k + 1
= 2k² + 3k + 1
= (k + 1)(2k + 1)    (factorising)
= (k + 1)(2(k + 1) − 1)    (which is P(k+1))

Hence true for all n ≥ 1 by induction. ∎

A correction to the slide. Slide 104 writes the expansion of k(2k − 1) as "(2k)² − k + 4k + 1". That should be 2k² − k + 4k + 1; "(2k)²" means 4k² and gives the wrong polynomial. The final answer on the slide is correct, so this is a typesetting slip, but copy the correct expansion into your notes.

Common mistakes

  • Skipping the base case, or "checking" it with only one side computed.
  • Never using the inductive hypothesis. If P(k) appears nowhere in the algebra, you have not done an induction.
  • Proving P(k+1) directly from first principles instead of from P(k). That proves the statement for one value, not for all.
  • Assuming P(k) for all k, which is what you are trying to prove. Assume it for a single arbitrary k.
  • Forgetting to show the final expression equals the right-hand side with n replaced by k+1. State the comparison explicitly.
  • Algebra slips in factoring. Check with n = 3 as a numerical sanity test.
  • No concluding sentence. It is a mark, and it costs nothing.

Direct proof — the sum of two even integers is even (teacher's slide 96)

Let x and y be even integers. By definition there are integers m and n with x = 2m and y = 2n. Then

x + y = 2m + 2n = 2(m + n).

Since m + n is an integer, x + y is twice an integer, hence even. ∎

The whole method in one line: take the definition apart, do the algebra, put the definition back together. A direct proof of "if n is odd then n² is odd" runs the same way: n = 2k + 1 gives n² = 4k² + 4k + 1 = 2(2k² + 2k) + 1, which is odd.

Contrapositive — if n² is even then n is even

The direct route starts from "n² is even", which is awkward: it tells you about a square, not about n. The contrapositive is easy, because it starts from "n is odd".

Contrapositive statement. If n is odd, then n² is odd.

Proof. Let n = 2k + 1 for some integer k. Then

n² = (2k + 1)² = 4k² + 4k + 1 = 2(2k² + 2k) + 1.

Since 2k² + 2k is an integer, n² is odd. ∎

Since P → Q ≡ ¬Q → ¬P, the contrapositive proves the original.

A source correction worth knowing. The teacher's slide 97 presents this same argument under the heading "Direct Proof". It is not a direct proof — it begins by assuming the negation of the conclusion, which is the contrapositive (or, if you prefer, a contradiction). The mathematics on the slide is correct and the method is valid; only the label is wrong. In an exam, name it "proof by contrapositive" and you cannot be marked down for it.

Contradiction — √2 is irrational (teacher's slide 100)

Suppose, for contradiction, that √2 is rational. Then √2 = a/b for integers a, b with b ≠ 0, chosen so that a and b have no common factor.

Squaring gives 2 = a²/b², so a² = 2b². Hence a² is even, and by the contrapositive result above, a is even. Write a = 2k. Substituting:

2b² = (2k)² = 4k², so b² = 2k².

Hence b² is even, so b is even as well. But then a and b share the factor 2, contradicting the choice that they have no common factor. The assumption is false, so √2 is irrational. ∎

Notice the shape: the contradiction is not "1 = 0" but "the pair has no common factor, and also has common factor 2". Any contradiction with an earlier statement or a known fact closes the proof.

Proof by cases — |x| + |x + 1| ≥ 1 for every real x (teacher's slide 107)

The absolute value behaves differently on different intervals, so split at the points where a term changes sign, x = −1 and x = 0. Three cases cover every real number.

Case 1, x ≤ −1. Then |x| = −x and |x + 1| = −(x + 1). So |x| + |x + 1| = −2x − 1. Since x ≤ −1 we have −2x ≥ 2, so −2x − 1 ≥ 1. ✓

Case 2, −1 < x < 0. Then |x| = −x and |x + 1| = x + 1. So the sum is 1, which is ≥ 1. ✓

Case 3, x ≥ 0. Then both are non-negative, so the sum is 2x + 1 ≥ 1. ✓

All cases give at least 1, and the cases cover all reals, so the inequality holds for every x. ∎

The two requirements are that the cases are exhaustive (no x is missed) and, ideally, mutually exclusive (no x is counted twice). Missing the boundary point x = −1 or x = 0 is the usual failure.

Counterexample — disproving a universal claim

Claim: "Every prime number is odd." A single counterexample kills it: 2 is prime and 2 is even. The claim is false, and no further work is needed.

Claim: "n² + n + 41 is prime for every positive integer n." True for n = 1, 2, …, 39, which is why it looks convincing. At n = 41 the value is 41² + 41 + 41 = 41(41 + 1 + 1) = 41 · 43, which is composite. Counterexample found.

One counterexample is a complete disproof of a "for all" statement. It is not a proof of anything else, so never use it to establish a universal claim.

Common mistakes

  • Calling a contrapositive proof a "direct proof". Different starting assumption, different name.
  • In a contradiction proof, assuming the negation of the hypothesis instead of the negation of the whole statement.
  • Proof by cases that misses a case or overlaps two cases at a boundary.
  • Using one example to "prove" a universal statement. Examples confirm; counterexamples refute.
  • In a counterexample, giving a value where the claim happens to hold. You need a value where it fails.
  • Ending a contradiction proof without saying which statement was contradicted.

(c) With p = "divisible by 4" and q = "even", the original is p → q.

Q6

(i) p → q ≡ ¬p ∨ q (implication law) ≡ q ∨ ¬p (commutative) ≡ ¬(¬q) ∨ ¬p (double negation) ≡ ¬q → ¬p (implication law, right to left).

(ii) (p ∧ q) ∨ (p ∧ ¬q) ≡ p ∧ (q ∨ ¬q) (distributive law, read right to left) ≡ p ∧ T (complementation) ≡ p (identity law).

Not equivalent to the converse. Take p = F, q = T. Then p → q is T, but the converse q → p is F. Since they differ in at least one row, they are not equivalent. (The converse is equivalent to the inverse, which is why both are "the other pair".)

Q7

(i) Tautology. (p ∧ q) → p ≡ ¬(p ∧ q) ∨ p ≡ (¬p ∨ ¬q) ∨ p ≡ (¬p ∨ p) ∨ ¬q ≡ T ∨ ¬q ≡ T.

(ii) Contradiction. p ↔ ¬p is true only if p and ¬p have the same value, which is impossible. Simplifying: (p → ¬p) ∧ (¬p → p) ≡ (¬p ∨ ¬p) ∧ (p ∨ p) ≡ ¬p ∧ p ≡ F.

(iii) Contingency. (p ∨ q) ∧ ¬p ≡ (p ∧ ¬p) ∨ (q ∧ ¬p) ≡ F ∨ (q ∧ ¬p) ≡ q ∧ ¬p. True when q is true and p is false (row FT), false elsewhere.

CNF of (p → q) ∧ (q → r): replace both arrows, giving (¬p ∨ q) ∧ (¬q ∨ r). Both parts are already clauses, so this is the CNF as it stands.

DNF of p ⊕ q: the exclusive or is true in the rows (T, F) and (F, T), so the DNF is (p ∧ ¬q) ∨ (¬p ∧ q).

Q8

(i) ∀x F(x). Negation: ¬∀x F(x) ≡ ∃x ¬F(x) — someone is not friendly.

(ii) ∃x H(x). Negation: ¬∃x H(x) ≡ ∀x ¬H(x) — nobody speaks Hindi (everyone does not speak Hindi).

(iii) ∃x (S(x) ∧ ¬B(x)). Negation: ∀x ¬(S(x) ∧ ¬B(x)) ≡ ∀x (¬S(x) ∨ B(x)) — every person is either not a student or was born in India, that is, every student was born in India.

Q10

(a) Let x = 2m + 1 and y = 2n + 1 for integers m, n. Then xy = 4mn + 2m + 2n + 1 = 2(2mn + m + n) + 1. Since 2mn + m + n is an integer, xy is odd. ∎

(b) Prove the contrapositive: if n is even, then 3n + 2 is even. Let n = 2k. Then 3n + 2 = 6k + 2 = 2(3k + 1), which is even. The contrapositive is true, so the original statement is true. ∎

(c) 9 is odd and 9 = 3 × 3, so it is not prime. One counterexample disproves the universal claim. (15, 21 and 25 work equally well.)

Q11

Disjoint sets: two sets with no element in common, that is A ∩ B = ∅. Example: {1, 2} and {3, 4}.

Proper subset: A ⊂ B when every element of A is in B and B has at least one extra element. Example: {1, 2} ⊂ {1, 2, 3}.

Cartesian product: A × B = {(a, b) | a ∈ A, b ∈ B}, the set of all ordered pairs. Example: {1, 2} × {x} = {(1, x), (2, x)}.

Partition of a set: a collection of non-empty, pairwise disjoint subsets whose union is the whole set. Example: { {1, 2}, {3} } partitions {1, 2, 3}.

Power set: P(A) = {X | X ⊆ A}, the set of all subsets of A; if |A| = n then |P(A)| = 2n. Example: P({1, 2}) = {∅, {1}, {2}, {1, 2}}.

Existential quantifier: ∃x P(x) asserts that P(x) is true for at least one x in the domain. Example: over the integers, ∃x (x² = 4) is true because x = 2 works.

Last-minute revision sheet

Definitions in one line each

  • Subset: A ⊆ B when every element of A is in B, that is ∀x(x ∈ A → x ∈ B).
  • Proper subset: A ⊆ B with A ≠ B.
  • Power set: P(A) = all subsets of A; |P(A)| = 2|A|.
  • Cartesian product: A × B = all ordered pairs (a, b); |A × B| = |A||B|.
  • Partition: non-empty, pairwise disjoint blocks whose union is the set.
  • Proposition: a declarative sentence that is true or false, not both.
  • Tautology / contradiction / contingency: always true / always false / mixed.
  • Logical equivalence: A ≡ B when they share a truth value in every row.
  • CNF / DNF: AND of ORs / OR of ANDs.
  • Predicate: a statement with variables, true or false only once they are fixed.
  • ∀ / ∃: true for every element / true for at least one element.
  • Induction: prove P(1), prove P(k) → P(k+1), conclude for all n ≥ 1.

Formulas to have at hand

  • p → q ≡ ¬p ∨ q    ¬(p → q) ≡ p ∧ ¬q    p → q ≡ ¬q → ¬p
  • ¬(p ∧ q) ≡ ¬p ∨ ¬q    ¬(p ∨ q) ≡ ¬p ∧ ¬q
  • p ↔ q ≡ (p → q) ∧ (q → p)
  • ¬∀x P(x) ≡ ∃x ¬P(x)    ¬∃x P(x) ≡ ∀x ¬P(x)
  • |A ∪ B ∪ C| = Σ|A| − Σ|A ∩ B| + |A ∩ B ∩ C|
  • |A only| = |A| − |A ∩ B| − |A ∩ C| + |A ∩ B ∩ C|

Procedures

  • Power set: count 2n, then list by size from ∅ up to the whole set.
  • Set equality: element argument (⟺ chain), membership table (2n rows), or laws with names.
  • Truth table: 2n rows, one column per sub-expression, compare the final columns.
  • Equivalence proof: start from the messier side, one law per line, name every law.
  • Tautology test: the final column all T; if mixed, it is a contingency.
  • CNF: kill ↔, kill →, push ¬ in, distribute ∨ over ∧.
  • DNF: kill ↔, kill →, push ¬ in, distribute ∧ over ∨ — or read the true rows of the table.
  • English to quantifiers: "all S are P" → ∀(S → P); "some S are P" → ∃(S ∧ P).
  • Induction: claim → base → hypothesis → step → "this is P(k+1)" → conclusion.
