1 · Relations: definition, notation, representation

Teacher's definition — Module 2 PPT, slide 8

A relation in mathematics is a subset of the Cartesian product of two sets. If X and Y are sets, then X × Y is the set of all ordered pairs (x, y) with x ∈ X and y ∈ Y. A relation R from X to Y is any subset of X × Y.

Simple meaning. A relation is a rule that links elements of one set to elements of another set — or links elements of the same set to each other. The link itself is recorded as an ordered pair. The order matters: (1, 2) is not the same pair as (2, 1).

Formal definition. A binary relation R from A to B is a subset of A × B. If (a, b) ∈ R we write a R b and say "a is related to b".

Notation — every symbol.

SymbolRead asMeaning
A × BA cross BAll ordered pairs (a, b) with a ∈ A and b ∈ B
(a, b) ∈ Rthe pair a b belongs to RThe link from a to b is part of the relation
a R ba is related to bSame statement, written in infix form
R ⊆ A × AR is a relation on AThe two sets are the same set A
DR(R)domain of RAll first coordinates that actually appear in R
RR(R)range of RAll second coordinates that actually appear in R
R−1inverse of RReverse every pair: (b, a) instead of (a, b)

Domain versus range — the trap. The domain and range are not automatically A and B. They are only the coordinates that actually occur. If A = {1, 2, 3} and R = {(1, 5)}, the domain is {1}, not A.

Four ways to write the same relation

  • Roster form: list the pairs — R = {(1, 2), (2, 4)}.
  • Set-builder form: state the rule — R = {(a, b) : b = 2a, a ∈ A, b ∈ B}.
  • Matrix form: rows are the elements of A, columns are the elements of B; put 1 where the pair is in R and 0 where it is not.
  • Digraph: vertices are elements, arrows are pairs. (You should be able to read one; drawing one belongs to the diagram task.)
Worked example — relation, domain, range, inverse, matrix
Question

Let A = {1, 2, 3} and B = {2, 4, 6}, and define R = {(a, b) : b = 2a}.

Find: R, its domain, its range, its inverse, and its matrix.

Solution

Step 1 — build the pairs. Take each a in A and compute 2a:

R = {(1, 2), (2, 4), (3, 6)}

Step 2 — domain and range. First coordinates: {1, 2, 3}. Second coordinates: {2, 4, 6}.

DR(R) = {1, 2, 3}    RR(R) = {2, 4, 6}

Step 3 — inverse. Reverse each pair.

R−1 = {(2, 1), (4, 2), (6, 3)}

Step 4 — matrix. Rows = 1, 2, 3; columns = 2, 4, 6. The pair (1, 2) puts a 1 in row 1, column 2; (2, 4) puts a 1 in row 2, column 4; (3, 6) puts a 1 in row 3, column 6.

Worked example — a relation on one set (teacher's Example 1.12)
Question

Let A = {1, 2, 3, 4} and let R = {(a, b) : a divides b}.

Find: R.

Solution

Go through each a and keep the multiples that are in A:

R = {(1,1), (1,2), (1,3), (1,4), (2,2), (2,4), (3,3), (4,4)}

Every element divides itself, so all four pairs (a, a) appear.

R = {(1,1), (1,2), (1,3), (1,4), (2,2), (2,4), (3,3), (4,4)}. This is the same relation used later in the poset section, and it is the standard example of a partial order.

Common mistakes in this section

  • Writing the domain as A without checking. The domain is only the first coordinates that occur.
  • Reversing only some pairs when forming R−1.
  • Forgetting that a relation on A is a subset of A × A, so both coordinates come from the same set.
  • In a matrix, reading columns as A. Rows are the first set, columns are the second set.

2 · Properties of relations

From here on, R is a relation on a set A, meaning R ⊆ A × A. Four properties decide almost every Module 2 question. Learn the definition and the test together.

Teacher's definitions — Module 2 PPT, slides 35, 41, 52, 53, 54

Reflexive: a R a, that is (a, a) ∈ R, for every a ∈ A.

Symmetric: if (a, b) ∈ R then (b, a) ∈ R, for all a, b ∈ A.

Antisymmetric: if (a, b) ∈ R and (b, a) ∈ R then a = b, for all a, b ∈ A.

Transitive: if (a, b) ∈ R and (b, c) ∈ R then (a, c) ∈ R, for all a, b, c ∈ A.

PropertyFormal statementHow to test itTypical example
Reflexive(a, a) ∈ R for every a ∈ AEvery element of A must appear as (a, a). One missing loop is enough to fail."is equal to", "≤", "divides"
Symmetric(a, b) ∈ R ⇒ (b, a) ∈ RFor every pair, look for its reverse. One one-way pair is enough to fail."is a sibling of", "is the same age as"
Antisymmetric(a, b) ∈ R and (b, a) ∈ R ⇒ a = bLook for a pair with a ≠ b where both directions occur. One such pair is enough to fail."≤", "divides", "is a subset of"
Transitive(a, b), (b, c) ∈ R ⇒ (a, c) ∈ RFor every chain a → b → c, check the shortcut a → c exists."≤", "divides", "is an ancestor of"

Symmetric versus antisymmetric — read this twice

They are not opposites. They talk about different situations.

  • Symmetric says: whenever a link goes one way, the reverse link must also exist. It forbids one-way links.
  • Antisymmetric says: if both directions exist, then the two elements must actually be the same element. It forbids two-way links between different elements.
  • A relation can be both: equality is symmetric and antisymmetric, because the only two-way pairs are (a, a).
  • A relation can be neither: on A = {1, 2, 3}, R = {(1, 2), (2, 1), (2, 3)} is not symmetric (no (3, 2)) and not antisymmetric ((1, 2) and (2, 1) with 1 ≠ 2).

The phrase to remember: symmetric = both directions always; antisymmetric = both directions only for the same element.

Systematic procedure for checking all four properties

  1. Write R in roster form and list the elements of A. Never test from the English description alone.
  2. Reflexive? Tick off (1,1), (2,2), … for every element. If any is missing, say so and name it.
  3. Symmetric? For each (a, b) with a ≠ b, check whether (b, a) is present. Name the first offender.
  4. Antisymmetric? For each pair with a ≠ b, check that both directions do not occur simultaneously. Name the first offender.
  5. Transitive? For each pair (a, b), look at every pair that starts at b, say (b, c); check (a, c). Name the first missing shortcut.
  6. Conclude with exactly the properties that hold. Do not claim a property you did not test.
Worked example A — an equivalence relation
Question

Let A = {1, 2, 3, 4} and R = {(1,1), (1,2), (2,1), (2,2), (3,3), (4,4)}.

Find: Test reflexivity, symmetry, antisymmetry and transitivity, and classify the relation.

Solution

Reflexive. (1,1), (2,2), (3,3), (4,4) are all present. ✓

Symmetric. The only non-diagonal pairs are (1,2) and (2,1), and each is the reverse of the other. ✓

Antisymmetric. (1,2) and (2,1) are both present, and 1 ≠ 2. So the condition fails. ✗

Transitive. Check the only possible chains: (1,2) followed by (2,1) needs (1,1) — present. (2,1) followed by (1,2) needs (2,2) — present. Chains through a diagonal pair only repeat the same pair. ✓

Final Answer

R is reflexive, symmetric and transitive, so it is an equivalence relation. It is not antisymmetric.

Answer-sheet form. Write the definition, then "LHS check → present/absent", then a one-line conclusion for each property. Four short blocks, not an essay.

Worked example B — a partial order
Question

Let A = {1, 2, 3, 6} and let x R y mean x divides y.

Find: Test all four properties and classify the relation.

Solution
R = {(1,1), (1,2), (1,3), (1,6), (2,2), (2,6), (3,3), (3,6), (6,6)}

Reflexive. 1|1, 2|2, 3|3, 6|6, so all four diagonal pairs occur. ✓

Symmetric. (1,2) ∈ R but (2,1) ∉ R. ✗

Antisymmetric. If x|y and y|x for positive integers then x = y. There is no pair of distinct elements with both directions. ✓

Transitive. If x|y and y|z then x|z. For example (1,2) and (2,6) give (1,6), which is present. ✓

Final Answer

R is reflexive, antisymmetric and transitive — a partial order, not an equivalence relation.

Common mistakes

  • Testing symmetry on (1,1). A diagonal pair is always its own reverse and proves nothing.
  • Claiming "not symmetric, therefore antisymmetric". The two properties are independent.
  • Checking only one chain for transitivity. One successful chain does not prove transitivity; one broken chain disproves it.
  • Forgetting that reflexivity is about every element of A, not just the elements that appear in some pair.

3 · Equivalence relations and equivalence classes

Teacher's definition — Module 2 PPT, slide 55

A relation R on a set A is an equivalence relation if R is reflexive, symmetric and transitive.

If R is an equivalence relation and a ∈ A, the equivalence class of a, written [a], is the set of all elements related to a:

[a] = {x ∈ A : (x, a) ∈ R}

The equivalence classes split A into non-overlapping blocks. Every element belongs to exactly one class.

How to recognise the question. Words like "same number of sides", "same remainder", "same city", "is similar to", "is congruent to", "same blood group" all signal an equivalence relation. The question usually asks you to verify the three properties and then list the classes.

Verified University question Summer 2026 · Q.1(a) · 5 marks

A digital geometry learning platform groups polygons based on the number of sides. Let A be the set of all polygons and define R = {(P1, P2) : P1 and P2 have the same number of sides}. Analyse whether R is an equivalence relation, verify the three properties, and construct equivalence classes for triangles, quadrilaterals and pentagons.

Full solution — polygon classification
Solution

Step 1 — Reflexive. Take any polygon P ∈ A. P has the same number of sides as itself. So (P, P) ∈ R for every P. ✓

Step 2 — Symmetric. Suppose (P1, P2) ∈ R. Then P1 and P2 have the same number of sides. The statement "P2 and P1 have the same number of sides" says exactly the same thing, so (P2, P1) ∈ R. ✓

Step 3 — Transitive. Suppose (P1, P2) ∈ R and (P2, P3) ∈ R. Let the common counts be n. Then P1 has n sides, P2 has n sides and P3 has n sides, so P1 and P3 have the same number of sides. Hence (P1, P3) ∈ R. ✓

Step 4 — Conclusion. R is reflexive, symmetric and transitive.

Step 5 — Equivalence classes. Group by the number of sides:

[triangle] = {all polygons with 3 sides}
[quadrilateral] = {all polygons with 4 sides}
[pentagon] = {all polygons with 5 sides}

These classes are disjoint (a polygon cannot have two different side counts) and together they cover every polygon in A. A triangle is not in the quadrilateral class, so the classes do not overlap.

Final Answer

R is an equivalence relation on A. Its classes are [triangle] (3 sides), [quadrilateral] (4 sides) and [pentagon] (5 sides); they are disjoint and cover A.

Step 6 — Interpretation (the last part carries marks). An equivalence relation turns a messy collection into labelled buckets. The platform can compute one number — the side count — and use it as a class label. Retrieval becomes "find the class, then search inside it", and no polygon is filed twice.

Answer-sheet form. Three labelled property blocks, a conclusion sentence, then one line per class, then two or three sentences of interpretation. That is a complete 5-mark answer.

Finding equivalence classes from a roster

  1. Start with the smallest element of A that has not been placed in a class.
  2. Collect every element related to it (look at both (a, x) and (x, a) — in an equivalence relation they come together).
  3. That collection is one class. Cross those elements off your list.
  4. Repeat with the next unplaced element until A is exhausted.
  5. Check: the classes must be disjoint, and their union must be A.
Worked example — classes from a finite relation (teacher's example)
Question

A = {1, 2, 3, 4, 5, 6} and

R = {(1,1), (1,5), (2,2), (2,3), (2,6), (3,2), (3,3), (3,6), (4,4), (5,1), (5,5), (6,2), (6,3), (6,6)}.

Find: All equivalence classes.

Solution

Start at 1. The pairs involving 1 are (1,1), (1,5), (5,1), (5,5). So [1] = {1, 5}.

Next unplaced element: 2. Pairs: (2,2), (2,3), (2,6), (3,2), (3,3), (3,6), (6,2), (6,3), (6,6). So [2] = {2, 3, 6}, and therefore [3] and [6] are the same set.

Next unplaced element: 4. Only (4,4), so [4] = {4}.

[1] = [5] = {1, 5}    [2] = [3] = [6] = {2, 3, 6}    [4] = {4}

Check. {1,5}, {2,3,6}, {4} are disjoint and together contain 1,2,3,4,5,6. ✓

Final Answer

The classes are {1, 5}, {2, 3, 6} and {4} — three classes, disjoint and covering A.

Note the wording. [2], [3] and [6] are three names for the same class. Writing "the classes are [2], [3] and [6]" as three separate classes is wrong; there are three classes, not six.

Common mistakes

  • Saying "reflexive because (1,1) is present" while ignoring the other elements.
  • Confusing the number of classes with the number of elements. Different representatives can name the same class.
  • Listing overlapping classes. If two classes share an element, the relation is not an equivalence relation (or the classes were computed wrongly).
  • Forgetting to conclude explicitly: "Hence R is an equivalence relation."

4 · Transitive closure and Warshall's algorithm

Teacher's definition — Module 2 PPT, slides 63 and 73

A relation R is transitive if (a, b) ∈ R and (b, c) ∈ R always forces (a, c) ∈ R.

The transitive closure of R is the smallest transitive relation that contains R. Equivalently, it is the set of all pairs (a, b) such that there is a directed path of length at least 1 from a to b.

For a relation on n elements, the transitive closure is an n × n Boolean matrix T where Tij = 1 if there is a path from i to j, and 0 otherwise.

Simple meaning. A direct edge tells you one flight. The closure tells you every city you can eventually reach, including by changing planes and including by going round a loop.

TermMeaning in plain words
Path of length 1A direct pair (a, b) already in R
Path of length 2a → x → b for some intermediate x
ReachabilityThere is a path of some length ≥ 1 from a to b
Transitive closure R+All reachable pairs
Reflexive–transitive closure R*R+ plus every (a, a). Some books call this "the" closure.

The update rule and what k means

Wij(k) = Wij(k−1) ∨ ( Wik(k−1) ∧ Wkj(k−1) )

W = matrix  ·  i = row (start)  ·  j = column (end)  ·  k = the intermediate vertex currently allowed  ·  ∨ = OR  ·  ∧ = AND

Read it as a sentence: "i reaches j if it already did, or if i reaches the current intermediate k and k reaches j."

What k means. After round k, the matrix records every path whose intermediate vertices come only from the first k elements. Round 1 allows paths through vertex 1 only. Round 2 allows paths through vertices 1 and 2. After n rounds, every possible intermediate vertex is allowed, so the matrix is the full transitive closure. That is why the outer loop must run over all vertices in order — you are widening the set of permitted stopovers one vertex at a time.

Procedure

  1. Label the elements in a fixed order and write the initial matrix W(0) with 1 for each direct pair.
  2. For k = first element, then second, … last element:
    • find every row i with a 1 in column k (i reaches k);
    • find every column j with a 1 in row k (k reaches j);
    • put a 1 in every position (i, j) formed by those rows and columns;
    • write down the new matrix and list the entries that changed.
  3. After the last round, read the pairs straight off the final matrix.
  4. Sanity check by tracing the actual paths for two or three pairs.

Note on the diagonal. We used paths of length at least 1, which is the convention in your lecture slides. If your lecturer instead starts the matrix with 1s on the diagonal, then (c,c) is also added and every diagonal entry is 1. Say which convention you used in your answer; both are defensible, but do not mix them.

Common mistakes

  • Using the updated matrix in the wrong places. Round k uses the matrix from round k−1 throughout.
  • Skipping rounds because "nothing seems to change". Write the matrix anyway — examiners award method marks.
  • Adding a pair because a path exists backwards. Paths are directed; (a, c) does not give (c, a).
  • Reading the closure off the original matrix instead of the final one.
  • Forgetting that a vertex on a cycle gets a self-pair, while a vertex not on a cycle does not (under the length ≥ 1 convention).

5 · Partial orders, posets and lattices

Definitions — Module 2 PPT, slides 53–54 and the syllabus's poset/lattice section

A relation R on A is a partial order if it is reflexive, antisymmetric and transitive. The pair (A, R) is then called a partially ordered set, or poset.

For elements a, b of a poset:

  • a ≤ b means (a, b) ∈ R. In a divisibility poset, a ≤ b means a divides b.
  • Minimal element: no element of A is strictly below it.
  • Maximal element: no element of A is strictly above it.
  • Least element: an element below every element of A.
  • Greatest element: an element above every element of A.
  • Lower bound of a set B: an element of A below every element of B. The largest such bound is the greatest lower bound, or meet (written a ∧ b).
  • Upper bound of B: an element of A above every element of B. The smallest such bound is the least upper bound, or join (written a ∨ b).
  • Lattice: a poset in which every pair of elements has both a meet and a join inside the set.

Why divisibility is a partial order. For positive integers: x|x (reflexive); x|y and y|x force x = y (antisymmetric); x|y and y|z force x|z (transitive). It is only a partial order because not every pair is comparable — 2 does not divide 3 and 3 does not divide 2.

Meet and join under divisibility. When the poset is divisibility on a set of positive integers, and the answers happen to lie in the set:

meet(a, b) = gcd(a, b)     join(a, b) = lcm(a, b)

This is a shortcut, not a definition. The definition is "greatest lower bound" and "least upper bound" within A. If the gcd or lcm is not an element of A, then that meet or join does not exist in the poset, and the poset is not a lattice.

When a poset is not a lattice — the counterexample you should memorise

Let S = {2, 3, 4, 6} under divisibility. Take the pair (3, 4).

gcd(3, 4) = 1, but 1 ∉ S. So no element of S is a lower bound of {3, 4} that is greatest — the meet does not exist inside S. Also lcm(3, 4) = 12 ∉ S. Either failure is enough.

Conclusion. (S, |) is a poset but not a lattice. A set being a poset never automatically makes it a lattice.

Chain and antichain — one line each

Chain: a subset in which every two elements are comparable. In the example, {1, 2, 6, 12, 24, 72} is a chain. Antichain: a subset in which no two distinct elements are comparable. In the example, {24, 36} and {2, 3} are antichains.

Common mistakes

  • Assuming "poset" implies "lattice". It does not; you must check every pair.
  • Computing gcd and lcm but forgetting to check that the answers lie in A.
  • Confusing minimal with least. A poset can have several minimal elements but at most one least element.
  • Drawing a Hasse diagram with an edge for every divisibility pair instead of only covering pairs.
  • Forgetting the diagonal pairs when listing R for a partial order.

Answer key

Q1

R = {(2, 4), (3, 6), (4, 8)}. Domain = {2, 3, 4}. Range = {4, 6, 8}. R−1 = {(4, 2), (6, 3), (8, 4)}. Matrix (rows 2,3,4; columns 4,6,8):

MR468
2100
3010
4001

Each element maps to exactly one double, so the 1s lie on the diagonal of this particular matrix — not because it is a diagonal relation, but because the columns happen to be the doubles in order.

Q2

Reflexive: yes, all four diagonal pairs are present. Symmetric: yes, the only off-diagonal pairs are (1,3) and (3,1). Antisymmetric: no, because (1,3) and (3,1) both occur with 1 ≠ 3. Transitive: yes — the only composite chains are (1,3)(3,1) → (1,1), present, and (3,1)(1,3) → (3,3), present.

So R is reflexive, symmetric and transitive: an equivalence relation, with classes [1] = [3] = {1, 3}, [2] = {2}, [4] = {4}.

Q3

Reflexive: a − a = 0 = 3 · 0, so 3 | (a − a) and a ≡ a (mod 3). Symmetric: if 3 | (a − b) then 3 | (b − a), so a ≡ b implies b ≡ a. Transitive: if 3 | (a − b) and 3 | (b − c) then 3 | ((a − b) + (b − c)) = (a − c), so a ≡ c. Hence an equivalence relation.

Classes: remainder 1 → {1, 4}; remainder 2 → {2, 5}; remainder 0 → {3, 6}. So [1] = [4] = {1,4}, [2] = [5] = {2,5}, [3] = [6] = {3,6}.

Q5

(a) Lattice. For any two powers of 2, gcd is the smaller and lcm is the larger, both in A. Example: gcd(4, 8) = 4, lcm(4, 8) = 8. It is a chain, and every chain is a lattice.

(b) Not a lattice. gcd(3, 4) = 1 ∉ S and lcm(3, 4) = 12 ∉ S, so the pair (3, 4) has neither a meet nor a join inside S.

Q7 — Winter 2025 storage plans

S = {1, 2, 4, 8, 16}. Pairs (x, y) with x | y: every (x, y) with x ≤ y in this chain, because each smaller power of 2 divides every larger one. That gives 5 + 4 + 3 + 2 + 1 = 15 pairs.

Covers: 1–2, 2–4, 4–8, 8–16 — a single vertical chain, because each element covers only the next one.

Lattice? Yes. gcd and lcm of two powers of 2 are the smaller and larger of the two, both in S. Example: meet(4, 8) = 4, join(4, 8) = 8.

Least: 1. Greatest: 16. It is a bounded lattice.

Q8

(a) gcd(6, 36) = 6, lcm(6, 36) = 36. Meet 6, join 36 (since 6 | 36, the pair is comparable).

(b) gcd(24, 72) = 24, lcm(24, 72) = 72. Meet 24, join 72.

(c) 8 ∉ A, so 8 is not an element of the poset at all. You cannot ask for its meet or join in A. The lesson: always check that the elements you are pairing belong to the set, and that gcd/lcm land inside the set.

Q9

Symmetric: every link that goes one way must also come back. Antisymmetric: if a link goes both ways, the two endpoints must be the same element. Symmetric forbids one-way links; antisymmetric forbids two-way links between different elements. Neither property implies the other.

Symmetric but not antisymmetric: R = {(1,1),(1,2),(2,1),(2,2),(3,3)} on {1,2,3}. (1,2) and (2,1) are both present with 1 ≠ 2.

Antisymmetric but not symmetric: R = {(1,1),(1,2),(2,2),(3,3)} — the "≤" relation on {1,2,3}. (1,2) has no reverse, but the only two-way pairs are diagonal.

Q10

A = {1, 2, 3, 4, 6, 12} under divisibility. 1 divides everything, so least = 1 and the only minimal element is 1. 12 is divisible by every element, so greatest = 12 and the only maximal element is 12.

Lattice? Check the awkward pair (4, 6): gcd(4, 6) = 2 ∈ A; lcm(4, 6) = 12 ∈ A. Pair (3, 4): gcd = 1 ∈ A; lcm = 12 ∈ A. Pair (2, 3): gcd = 1, lcm = 6. Pair (6, 4) done. Checking all pairs, gcd and lcm always lie in A, so it is a lattice.

Last-minute revision sheet

Definitions in one line each

  • Relation: a subset of A × B.
  • Domain / range: first / second coordinates that actually occur.
  • Reflexive: (a, a) ∈ R for all a.
  • Symmetric: (a, b) ∈ R ⇒ (b, a) ∈ R.
  • Antisymmetric: (a, b), (b, a) ∈ R ⇒ a = b.
  • Transitive: (a, b), (b, c) ∈ R ⇒ (a, c) ∈ R.
  • Equivalence relation: reflexive + symmetric + transitive.
  • Equivalence class [a]: all elements related to a.
  • Transitive closure: all (a, b) with a path from a to b.
  • Partial order: reflexive + antisymmetric + transitive.
  • Poset: a set with a partial order.
  • Lattice: every pair has a meet and a join in the set.

Procedures

  • Check properties: roster → reflexive → symmetric → antisymmetric → transitive → conclude.
  • Prove equivalence: three labelled proofs + "hence equivalence relation".
  • Classes: pick unplaced element → collect related elements → cross off → repeat → check disjoint and covering.
  • Warshall: W(0) → rounds k = 1…n → record changes → read pairs.
  • Lattice test: every pair → gcd and lcm → both in A? → witness pair if not → conclusion.

Sanity checks before you hand in

  • Did you list the elements of A before testing reflexivity?
  • Did you give a named counterexample for every property you rejected?
  • In Warshall, did you write a matrix for every k, even when nothing changed?
  • Did you check that gcd and lcm belong to the given set?
  • Did you write a conclusion sentence?
