1 · Graphs and Types of Graphs (6.1)

Teacher’s starting point: vertices and edges

A graph G = (V, E) is a non-empty finite set V of vertices together with a set E of edges. Each edge joins a pair of vertices. In an undirected graph the pair is unordered: the edge {u, v} is the same as {v, u}.

Two vertices joined by an edge are adjacent. The edge is incident with both of them. The degree of a vertex deg(v) is the number of edge-ends at that vertex. A loop contributes 2, because both ends of the loop sit on the same vertex.

A loop is an edge from a vertex to itself. Multiple edges are two or more edges joining the same pair of vertices. A graph with neither is simple.

The Handshaking Lemma

Σ deg(v) = 2|E|

Each edge has two ends, so it adds 1 to the degree of each endpoint — two in total. A loop adds 2 to one vertex, which is still two ends.

One consequence is used constantly in exams: the number of vertices with odd degree is always even. If a question hands you a degree list with an odd number of odd degrees, no such graph exists.

Example 1: Reading degrees from a drawing
Question

For the graph in Figure 1, write down the degree of every vertex. Verify the handshaking lemma and count the odd-degree vertices.

Solution

Count edge-ends at each vertex. The loop at C is one edge but contributes two ends.

deg(A) = 2 + 1 = 3
deg(B) = 2 + 1 = 3
deg(C) = 1 + 1 + 2 = 4
deg(D) = 1 + 1 = 2

Total: 3 + 3 + 4 + 2 = 12. The graph has 6 edges, so 2|E| = 12.

Final Answer

Degrees are 3, 3, 4, 2. The sum is 12 = 2 × 6, so the lemma holds. There are two odd-degree vertices (A and B).

Example 2: A degree sequence that cannot exist
Question

Can a graph have five vertices with degrees 3, 3, 3, 2, 2? Justify your answer.

Solution

Add the degrees and test the handshaking lemma.

3 + 3 + 3 + 2 + 2 = 13
2|E| must be even

13 is odd, so no integer |E| can satisfy 2|E| = 13. Equivalently, the list has three odd degrees, and odd-degree vertices must occur in pairs.

Final Answer

No. The degree sum is odd, so such a graph cannot exist.

Example 3: Edges in complete and complete bipartite graphs
Question

Find the number of edges in K₇ and in K₃,₄.

Solution

In Kₙ every pair of the n vertices is joined:

|E(Kₙ)| = n(n − 1) / 2
|E(K₇)| = 7 × 6 / 2 = 21

In Kₘ,ₙ every vertex of one part is joined to every vertex of the other, and there are no edges inside a part:

|E(Kₘ,ₙ)| = m × n
|E(K₃,₄)| = 3 × 4 = 12
Final Answer

K₇ has 21 edges; K₃,₄ has 12 edges.

Two facts worth memorising

Bipartite test: a graph is bipartite if and only if it has no odd cycle. C₆ passes; a triangle fails; K₄ fails because it contains triangles.

Regular graphs: if every vertex has degree r, then 2|E| = n·r. So a 3-regular graph on 5 vertices would need |E| = 15/2, which is impossible. This parity check appears in Question 1 parts.

Graph drawings are not unique. The same graph can look like a square, a ring or a star depending on where the vertices are placed. Section 5 turns that observation into a precise test: isomorphism.

2 · Graph Representation (6.2)

Syllabus topic; not developed in the slide deck

A graph can be stored in several equivalent ways. The three that appear in discrete-mathematics courses are the adjacency list, the adjacency matrix and the incidence matrix. Each answers a different question quickly: the list is compact, the adjacency matrix answers “are these two adjacent?” in one lookup, and the incidence matrix records which edges touch which vertices.

Throughout this section the example graph is G = (V, E) with V = {1, 2, 3, 4} and E = {12, 13, 24, 34}. It is a 4-cycle drawn as 1–2–4–3–1, and every vertex has degree 2.

For each vertex, list its neighbours. The total length of all lists is 2|E| in an undirected graph, so the storage is proportional to the number of edges.

Conventions for loops and multiple edges

For a multigraph, the adjacency entry aᵢⱼ is the number of edges between i and j. For a loop, this guide writes 2 on the diagonal, so that row sums still equal degrees. Some books write 1; either is acceptable if you state the convention.

In the incidence matrix, a loop occupies a column with a single entry 2 in its vertex’s row. A directed edge from u to v is normally recorded as −1 at u and +1 at v.

Question

A simple graph on vertices {1, 2, 3, 4} has adjacency matrix with 1s at positions (1,2), (2,1), (2,3), (3,2), (3,4), (4,3), (4,1), (1,4). List the edges, find each degree, and identify the graph.

E = {12, 23, 34, 14}

Which representation to use

Use an adjacency list for sparse graphs: storage is O(V + E). Use an adjacency matrix when you need fast adjacency tests or when the graph is dense: storage is O(V²), but aᵢⱼ is a direct lookup. Use an incidence matrix when the edges themselves matter — for example, when proving properties of circuits or cuts.

3 · Subgraphs and Operations on Graphs (6.3)

Syllabus topic; not developed in the slide deck

A graph H = (V′, E′) is a subgraph of G = (V, E) when V′ ⊆ V, E′ ⊆ E, and every edge in E′ has both endpoints in V′. You obtain a subgraph by deleting vertices, deleting edges, or both.

If V′ = V, the subgraph is spanning. If E′ contains every edge of G whose endpoints lie in V′, the subgraph is induced by V′ and is written G[V′]. Deleting a vertex forces you to delete its incident edges, and deleting only those gives the induced subgraph on the remaining vertices. A subgraph on the same vertices that is missing some further edge is not induced.

Example 6: Deleting a vertex versus an induced subgraph
Question

Let V = {1, 2, 3, 4, 5} and E = {12, 23, 34, 45, 51, 13}.

(a) Delete vertex 3 and all incident edges. (b) Take the subgraph induced by {1, 2, 4, 5}. (c) Delete vertex 3 and also edge 12. Which results are induced subgraphs?

Solution

(a) Vertex 3 is incident with 23, 34 and 13. Removing those leaves 12, 45 and 51.

(b) The induced subgraph keeps every edge with both ends in {1, 2, 4, 5}, which is again 12, 45 and 51. So (a) and (b) are the same graph.

(c) Dropping 12 as well leaves only 45 and 51, and vertex 2 becomes isolated. Both ends of 12 are still present, so an induced subgraph would have to keep it.

(a) E′ = {12, 45, 51}  ·  (b) E′ = {12, 45, 51}  ·  (c) E′ = {45, 51}
Final Answer

(a) and (b) are induced, and they are equal. (c) has the same vertices but is not induced, because it omits edge 12.

Example 7: Union, intersection and ring sum
Question

On the vertex set {1, 2, 3, 4, 5}, let H₁ have edges {12, 23, 34} and H₂ have edges {23, 34, 45}. Find H₁ ∪ H₂, H₁ ∩ H₂ and H₁ ⊕ H₂.

Solution
H₁ ∪ H₂ = {12, 23, 34, 45}
H₁ ∩ H₂ = {23, 34}
H₁ ⊕ H₂ = {12, 45}

The union is the path 1–2–3–4–5. The intersection is the middle path 2–3–4. The ring sum drops the shared edges and leaves the two ends.

Final Answer

Union: 4 edges. Intersection: 2 edges. Ring sum: {12, 45}.

Example 8: A spanning subgraph that is a cycle
Question

Using G from Example 6, find a spanning subgraph that is a 5-cycle.

Solution

A spanning subgraph must keep all five vertices. The outer ring of G is 1–2–3–4–5–1, using edges 12, 23, 34, 45, 51. Dropping the chord 13 removes the only extra edge.

Final Answer

The spanning subgraph with edges {12, 23, 34, 45, 51} is C₅.

4 · Walk, Path, Circuit and Connectedness (6.4)

Teacher’s vocabulary: how to move through a graph

A walk is an alternating sequence of vertices and edges, v₀, e₁, v₁, e₂, …, eₖ, vₖ, where each edge eᵢ joins vᵢ₋₁ to vᵢ. Its length is the number of edges, k. A walk is closed if it starts and ends at the same vertex, and open otherwise.

A trail is a walk with no repeated edge. A path is a walk with no repeated vertex (apart from the starting vertex when the walk is closed). A circuit is a closed trail. A cycle is a closed path with at least three vertices.

path ⊂ trail ⊂ walk  ·  cycle ⊂ circuit ⊂ closed walk

Every path is a trail, because repeating a vertex would force a repeated edge. The converse fails: you can revisit a vertex without reusing an edge.

A graph is connected if every pair of vertices is joined by a path. If not, it is disconnected. A component is a maximal connected subgraph: a connected piece that cannot be extended without leaving it. The number of components is written c(G). An isolated vertex is a component of size 1.

Example 10: Components and connectivity

Useful lemma for proofs

Every u–v walk contains a u–v path: if a vertex repeats, cut out the section between the two visits. Repeating this leaves a walk with no repeated vertex. This is why “connected” can be defined using walks or paths without changing the meaning — and it is the standard first step in proving that connectedness is an equivalence relation, whose classes are the components.

5 · Homomorphism and Isomorphism (6.5)

Teacher’s definition: same structure, different labels

An isomorphism from G to H is a bijection f : V(G) → V(H) such that, for all vertices u, v in G:

uv ∈ E(G) ⇔ f(u)f(v) ∈ E(H)

The double arrow matters. The map must preserve edges and non-edges. If two graphs are isomorphic we write G ≅ H; they are the same graph with renamed vertices, so every structural property is identical.

An isomorphism invariant is a property preserved by every isomorphism. To prove graphs are not isomorphic, find one invariant that differs. Common invariants: number of vertices, number of edges, degree sequence, number of components, number and lengths of cycles, whether the graph is bipartite, connectivity, and the number of cut vertices.

InvariantWhy it must match
|V| and |E|A bijection pairs vertices one-to-one and edges one-to-one.
Sorted degree sequenceAdjacency is preserved, so each vertex keeps its number of neighbours.
Number of componentsA path between two vertices maps to a path between their images.
Cycle lengthsA cycle maps to a cycle of the same length.
BipartitenessAn odd cycle cannot appear or disappear under a bijection.
Cut verticesRemoving a vertex and its image must break the graph in the same way.

All five edges map to edges, so the five distinct edges of G map onto the five distinct edges of H. A non-edge also behaves: ac maps to 21, which is not an edge of H.

Example 12: When the degree sequence is not enough
Question

Show that a 6-cycle and two disjoint triangles are not isomorphic, even though both have 6 vertices, 6 edges and every degree equal to 2.

Solution

The easy invariants agree, so look at components.

c(C₆) = 1  ·  c(2C₃) = 2

An isomorphism preserves paths, so it must map a connected graph to a connected graph. It cannot map the single 6-cycle onto two separate triangles.

Final Answer

They are not isomorphic: C₆ is connected, while the two triangles form two components. Identical degree sequences do not prove isomorphism.

Homomorphism — the weaker map

A homomorphism f : V(G) → V(H) only requires that adjacent vertices map to adjacent vertices:

uv ∈ E(G) ⇒ f(u)f(v) ∈ E(H)

It need not be injective, and it has no inverse requirement. Several vertices of G may collapse onto one vertex of H. An isomorphism is the special case where f is also a bijection and the implication runs both ways.

Example 13: A homomorphism that is not an isomorphism
Question

Let G = C₄ with vertices 1–2–3–4–1, and let H = K₂ with vertices x, y. Define f(1) = f(3) = x and f(2) = f(4) = y. Show that f is a homomorphism but not an isomorphism.

Solution

Check each edge of the 4-cycle:

12 → xy   23 → yx   34 → xy   41 → yx

Every image is the single edge xy, so adjacency is preserved and f is a homomorphism. But f(1) = f(3), so f is not injective; also |V(G)| = 4 and |V(H)| = 2, so no bijection exists.

Final Answer

f is a homomorphism but not an isomorphism. In fact it is exactly a proper 2-colouring of the bipartite graph C₄.

Terminology note — course slides vs standard texts

The slide titled “Homomorphism” describes obtaining one graph from another by subdividing edges — inserting a new degree-2 vertex on an edge. Standard texts call that relation homeomorphism, not homomorphism. For example, subdividing one edge of C₄ gives C₅: the graphs are homeomorphic, but not isomorphic, because they have different numbers of vertices.

In this course, follow the slide’s usage when the question uses the course’s wording. If a question asks for the standard definition, use the adjacency-preserving map above and mention the distinction in one sentence. Do not silently swap the two terms.

6 · Euler and Hamiltonian Graphs (6.6)

Teacher’s two travelling problems

An Euler trail is a trail that uses every edge of a graph exactly once. An Euler circuit is a closed Euler trail — it starts and ends at the same vertex. A graph with an Euler circuit is called Eulerian. The edges are the object of the exercise: every edge once, vertices may repeat.

A Hamiltonian path visits every vertex exactly once. A Hamiltonian cycle is a closed Hamiltonian path. Here the vertices are the object: every vertex once, edges may be left unused.

The two problems look similar and are tested completely differently. Euler has a clean degree test. Hamiltonian has no simple test that works for every graph.

Euler's Theorem

Suppose all edges of G lie in one connected component — isolated vertices are ignored. Then:

  • G has an Euler circuit if and only if every vertex has even degree.
  • G has an Euler trail but no Euler circuit if and only if exactly two vertices have odd degree. The trail must start at one odd vertex and end at the other.
  • If there are 4 or more odd vertices, there is no Euler trail at all.

Why parity is necessary: every time a trail enters a vertex it must leave again, so visits use edges in pairs. Only the start and end of an open trail can have an unpaired edge. A circuit has no unpaired ends, so every degree is even.

Why it is sufficient: repeatedly walk without reusing an edge until you return to the start; this closes a cycle. If edges remain, splice another cycle into a vertex already on the trail. Every vertex has even degree, so the walk never gets stuck except at its starting vertex.

Example 15: Euler trail with exactly two odd vertices
Question

For V = {1, 2, 3, 4, 5} and E = {12, 23, 34, 45, 51, 13}, decide whether an Euler circuit or an Euler trail exists. If a trail exists, write one.

Solution

Degrees: 1 is incident with 12, 51, 13 → 3. Vertex 2 has 12, 23 → 2. Vertex 3 has 23, 34, 13 → 3. Vertices 4 and 5 each have 2. There are exactly two odd vertices, 1 and 3.

So there is no Euler circuit, but there is an Euler trail from 1 to 3. One trail is:

1 –2– 3 –4– 5 –1– 3

Edges: 12, 23, 34, 45, 51, 13. All six are used once, and the endpoints are the odd vertices.

Final Answer

No Euler circuit. An Euler trail exists, for example 1-2-3-4-5-1-3, starting at 1 and ending at 3.

Hamiltonian Graphs

A Hamiltonian cycle uses every vertex exactly once and returns to the start. Unlike Euler’s problem, there is no degree condition that is both necessary and sufficient. You test by construction or by finding a structural obstruction.

Necessary conditions are useful for saying “no”:

  • For a Hamiltonian cycle, the graph must be connected and must have at least 3 vertices.
  • A graph with a cut vertex has no Hamiltonian cycle. The cycle can pass through that vertex only twice, so it can cover at most two of the components of G − v.
  • In a bipartite graph, a Hamiltonian cycle must alternate between the two parts, so the parts must have equal size. For a Hamiltonian path, their sizes can differ by at most 1.

These conditions can rule a graph out, but passing them does not guarantee a cycle. Always exhibit the cycle when the answer is yes.

Example 16: Hamiltonian cycle in the teacher’s graph
Question

For Figure 6, write a Hamiltonian cycle and a Hamiltonian path. State the degree of each vertex.

Solution

Walk around the outer pentagon:

A – B – C – D – E – A

This visits A, B, C, D, E exactly once and returns to A. Drop the closing edge EA to get the Hamiltonian path A–B–C–D–E.

Degrees: A is joined to B, E, C → 3. B is joined to A, C, D → 3. C is joined to B, D, A → 3. D is joined to C, E, B → 3. E is joined to D, A → 2. The chords raise four degrees but do not affect the cycle.

Example 17: A graph with no Hamiltonian cycle
Question

Two triangles share the single vertex A: the first is A–B–C–A, the second is A–D–E–A. Show that the graph has no Hamiltonian cycle, but does have a Hamiltonian path.

Solution

Removing A leaves two separate edges, BC and DE, so c(G − A) = 2. A is a cut vertex.

A Hamiltonian cycle would have to enter one triangle through A and later return to A to reach the other triangle. That uses A twice, which a cycle cannot do. So no Hamiltonian cycle exists.

A Hamiltonian path is still possible: start at B, cross A once, and finish in the other triangle.

B – C – A – D – E

This visits all five vertices once; it is a path, not a cycle.

Final Answer

No Hamiltonian cycle, because A is a cut vertex. A Hamiltonian path exists: B-C-A-D-E.

7 · Planar Graphs (6.7)

Teacher’s planar-graph slides

A graph is planar if it can be drawn in the plane so that no two edges cross. The drawing may be redrawn; planarity is a property of the graph, not of one particular picture. A planar drawing divides the plane into regions called faces. One of them is unbounded and is called the outer face.

A plane graph is a planar graph together with a crossing-free drawing. The same planar graph can have different faces in different drawings, but the number of faces is fixed.

Euler's Formula for Planar Graphs

V − E + F = 2

For a connected plane graph. V = vertices, E = edges, F = faces including the outer face. If the graph has c components, the formula becomes V − E + F = 1 + c.

The degree of a face is the number of edge-sides on its boundary; a bridge is counted twice because both sides border the same face. Summing over all faces counts every edge twice:

Σ deg(f) = 2E
Three consequences used in exams

Edge bound: for a simple connected planar graph with V ≥ 3, every face has degree at least 3, so 3F ≤ 2E. Substituting into Euler’s formula gives:

E ≤ 3V − 6

Triangle-free bound: if the graph is also bipartite, it has no triangles, so every face has degree at least 4:

E ≤ 2V − 4

Minimum degree: a simple planar graph always has a vertex of degree at most 5. Otherwise 2E ≥ 6V, contradicting E ≤ 3V − 6.

These inequalities are necessary, not sufficient. Passing them does not prove a graph is planar; failing them proves it is not.

Example 18: Euler’s formula for K₄
Question

Verify Euler’s formula and the face-degree identity for the drawing in Figure 7. Is K₄ planar?

Solution

There are 4 vertices, 6 edges and 4 faces: three bounded triangles and the unbounded outer region.

V − E + F = 4 − 6 + 4 = 2

Each of the four faces is bounded by a triangle, so every face degree is 3:

Σ deg(f) = 3 + 3 + 3 + 3 = 12 = 2 × 6

The bound also holds: 6 ≤ 3(4) − 6 = 6, so K₄ saturates the planar edge bound.

Final Answer

K₄ is planar. V−E+F = 2, every face has degree 3, and E = 3V−6.

Example 19: The cube graph
Question

The cube graph has 8 vertices and 12 edges and is planar. Find the number of faces, check Euler’s formula and the edge bound, and find the degree of each face.

Solution

Rearrange Euler’s formula:

F = 2 − V + E
= 2 − 8 + 12 = 6

These are the six square faces of the cube, including the outer face in a flat drawing. The bound is E ≤ 3V − 6 = 18, and 12 ≤ 18. If every face has degree d, then 6d = 2E = 24.

Final Answer

F = 6; each face has degree 4; 6 × 4 = 24 = 2 × 12.

Example 20: Why K₅ and K₃,₃ are not planar
Question

Use the planar edge bounds to prove that (a) K₅ and (b) K₃,₃ are not planar.

Solution

(a) K₅ has V = 5 and E = 10. If it were planar, the simple-graph bound would require:

E ≤ 3V − 6
10 ≤ 3(5) − 6 = 9

This is false, so K₅ is not planar.

(b) K₃,₃ has V = 6 and E = 3 × 3 = 9. It is bipartite, so it has no triangles and the stronger bound applies:

E ≤ 2V − 4
9 ≤ 2(6) − 4 = 8

This is false, so K₃,₃ is not planar. Using only 3V − 6 would give 9 ≤ 12, which proves nothing — the bipartite bound is the one that works.

Final Answer

Both violate a necessary planar bound: K₅ has 10 > 9, and K₃,₃ has 9 > 8. Neither is planar.

8 · Cut Sets and Cut Vertices (6.8)

Syllabus topic; not developed in the slide deck

A cut vertex (also called an articulation point) is a vertex whose removal increases the number of components. In a connected graph, removing a cut vertex leaves at least two components. A bridge or cut edge is an edge whose removal increases the number of components.

A cut set is a set of edges whose removal disconnects the graph. It is minimal if no proper subset of it is also a cut set. The edge connectivity λ(G) is the size of a smallest cut set of a connected graph. The vertex connectivity κ(G) is the smallest number of vertices whose removal disconnects the graph or leaves a single vertex.

κ(G) ≤ λ(G) ≤ δ(G)

δ(G) is the minimum degree. Removing all edges at a minimum-degree vertex isolates it, which gives λ ≤ δ. Every edge cut can be blocked by removing one endpoint of each cut edge, which gives κ ≤ λ.

Two useful facts

An edge is a bridge exactly when it lies on no cycle. If an edge lies on a cycle, there is an alternative route between its endpoints, so deleting it does not disconnect them.

A connected graph with at least three vertices and no cut vertex is called 2-connected or biconnected. Such a graph has at least two internally vertex-disjoint paths between every pair of vertices — a necessary condition for a Hamiltonian cycle, though not a sufficient one.

Example 21: Cut vertices, bridges and connectivity of Figure 8
Question

For Figure 8, list all cut vertices and all bridges. Find κ(G), λ(G) and δ(G), and verify the inequality between them.

Solution

Delete each vertex in turn. Removing C leaves the edge AB and the triangle D–E–F: two components. Removing D likewise leaves A–B–C and EF: two components. Removing A leaves B–C–D–E–F connected, so A is not a cut vertex; the same holds for B, E and F.

Edge CD is the only edge not on a cycle. Deleting it separates the triangles, while deleting a triangle edge leaves a path through the other two sides.

Degrees: A = 2, B = 2, C = 3, D = 3, E = 2, F = 2, so δ(G) = 2. One vertex (C) is enough to disconnect, so κ = 1. One edge (CD) is enough, so λ = 1.

κ = 1 ≤ λ = 1 ≤ δ = 2
Final Answer

Cut vertices: C and D. Bridge: CD. κ = 1, λ = 1, δ = 2.

Example 22: Connectivity of two triangles sharing a vertex
Question

Two triangles share the single vertex x: x–a–b–x and x–c–d–x. Find κ, λ and δ. Why is λ not 1 even though the graph has a cut vertex?

Solution

Removing x leaves the two edges ab and cd, so x is a cut vertex and κ = 1. The minimum degree is 2 (vertices a, b, c, d each have degree 2), so δ = 2.

There is no bridge: every edge lies on a triangle, so deleting one edge leaves the other two sides as an alternative route. To disconnect the graph by deleting edges, both edges xa and xb must go, or both xc and xd. Hence λ = 2.

κ = 1 ≤ λ = 2 ≤ δ = 2
Final Answer

κ = 1, λ = 2, δ = 2. A cut vertex is a single point of failure for vertices, but every edge still has a backup route, so no single edge disconnects the graph.

9 · Real-Life Applications (6.9)

Syllabus line: “Real life applications of Graph Theory”

The syllabus asks for applications, not new theory. These examples connect the definitions above to systems you already use. They are illustrative; they are not additional examinable definitions.

Routing and navigation

Roads, flights and packet networks are weighted graphs: vertices are places, edges are links, and weights are distance, time or cost. A shortest-path algorithm such as Dijkstra’s grows a tree of cheapest routes from the source. The same model answers “which route has the fewest hops?” when every edge has weight 1.

Network design and minimum cost

Connecting n offices with the cheapest cabling is a minimum spanning tree problem: keep all vertices, choose n − 1 edges, avoid cycles. Kruskal’s and Prim’s algorithms both build such a tree. A spanning tree is also the sparsest connected spanning subgraph of a network.

Reliability and cut sets

A cut set is exactly the list of links whose failure splits a network. A bridge is a single link with no backup. Network planners compare κ and λ to decide how much redundancy is needed: a graph with λ = 1 has a single point of failure, while λ = 3 survives any two link failures.

Scheduling and dependencies

Course prerequisites, build steps and project tasks form a directed graph. A topological order is a sequence that respects every arrow, and a cycle means the dependency graph is impossible to schedule. Graph colouring assigns times or rooms so that conflicting tasks differ; this is the self-learning topic on the next page.

Social, biological and recommendation networks

People and friendships, proteins and interactions, users and purchases — all are graphs. Components find isolated groups, centrality measures find influential vertices, and clustering coefficients measure how tightly neighbours know each other. Isomorphism matters when two datasets are the same network under different labels.

Solution

Q.6(b) · Euler and Hamiltonian routes for a conference venue MUMBAI UNIVERSITY

A research conference venue is modeled as graph V = {A, B, C, D, E, F} with edges:
E = {AB, AC, BC, BD, CE, DE, DF, EF}

i. Determine existence of Euler Path, Euler Circuit, Hamiltonian Path, Hamiltonian Circuit.
ii. Construct them if they exist.
iii. Explain what this means for planning visitor flow, inspection rounds, and avoiding repeated walking paths.

Solution

Degrees first.

CAC, BC, CE3
DBD, DE, DF3
ECE, DE, EF3

There are four odd-degree vertices: B, C, D and E. An Euler circuit needs 0 odd vertices and an Euler trail needs exactly 2, so neither exists.

Hamiltonian circuit. Try the circuit

A – B – D – F – E – C – A

Its edges are AB, BD, DF, FE, EC, CA, all present in E. It visits all six vertices exactly once and returns to A, so it is a Hamiltonian circuit.

A – B – D – F – E – C

This is a Hamiltonian path. The alternative A–B–C–E–D–F also works.

No Euler path and no Euler circuit (four odd vertices). Hamiltonian circuit: A-B-D-F-E-C-A. Hamiltonian path: A-B-D-F-E-C. Visitors can tour every room once, but no route covers every corridor exactly once.

Syllabus Self-Learning Topics

These topics are listed for self-learning in the syllabus. They are not developed in the Module 6 lecture slides and are not part of the standard 8-hour exam pattern. Treat them as assignment, viva or project material. The three paragraphs below give the vocabulary and the main result for each, so you can read further without starting from zero.

Network flow. A flow network is a directed graph with a capacity on every edge, a source s and a sink t. A feasible flow respects capacity and conserves flow at every vertex except the source and sink. The value of the flow is what leaves s. The max-flow min-cut theorem states that the maximum flow equals the minimum capacity of an s–t cut. Ford–Fulkerson finds it by repeatedly pushing flow along an augmenting path in the residual graph.

Graph colouring in scheduling. A proper colouring gives adjacent vertices different colours; the smallest number of colours is the chromatic number χ(G). Build a conflict graph — vertices are tasks, edges are clashes — and colours become time slots, rooms or registers. A greedy colouring uses at most Δ + 1 colours, where Δ is the maximum degree, though the true chromatic number can be smaller. Trees are 2-colourable; odd cycles need 3; Kₙ needs n.

Optimisation: shortest paths, spanning trees, clustering. Dijkstra’s algorithm finds shortest paths from one source when weights are non-negative. Kruskal’s and Prim’s algorithms find a minimum spanning tree, which connects all vertices at least cost. Clustering groups vertices that are more tightly connected to each other than to the rest; the local clustering coefficient of a vertex is 2Eᵥ / (deg(v)(deg(v) − 1)), the fraction of possible neighbour pairs that are actually joined.

Σ deg(v) = 15  but  Σ deg(v) = 2|E|

Common Mistakes

  • Counting a loop once. A loop contributes 2 to the degree because both ends meet the same vertex. It is still one edge.
  • Mixing up Euler and Hamiltonian. Euler covers every edge once; Hamiltonian visits every vertex once. The tests are completely different.
  • Using the degree sequence to prove isomorphism. Equal degree sequences are necessary, not sufficient. C₆ and two triangles have the same degree sequence and are not isomorphic.
  • Checking only edges, not non-edges. An isomorphism must preserve non-adjacency too. A bijection that happens to map edges to edges is only a homomorphism until the reverse implication is checked.
  • Forgetting the outer face. Euler’s formula counts the unbounded region. K₄ has 4 faces, not 3.
  • Using E ≤ 3V − 6 on a bipartite graph. For triangle-free graphs the sharper bound is E ≤ 2V − 4. For K₃,₃, the first bound gives 9 ≤ 12 and proves nothing; the second gives 9 ≤ 8 and settles it.
  • Treating a planar inequality as a proof of planarity. The bounds are necessary conditions. Passing them does not construct a crossing-free drawing.
  • Calling every closed walk a cycle. A cycle has no repeated vertex except the start and end. A closed walk may repeat vertices and edges.
  • Assuming Hamiltonian conditions are sufficient. A graph can satisfy the degree or bipartite conditions and still have no Hamiltonian cycle. Construct the cycle, or name a cut vertex, before concluding.
  • Confusing a cut set with a cut vertex. A cut set is a set of edges; a cut vertex is a single vertex. A minimal cut set cannot be made smaller and still disconnect the graph.
  • Using c(G − v) > c(G) carelessly. For a connected graph, a cut vertex makes the count at least 2; for a disconnected graph, compare before and after, not with 1.
  • Forgetting that isolated vertices do not block an Euler circuit. Euler’s theorem applies to the component containing the edges. A separate isolated vertex does not remove the circuit.

Decision checklist

  1. Euler? Count odd degrees. 0 → circuit; 2 → trail between them; 4 or more → neither.
  2. Hamiltonian? Try to build a cycle. If you cannot, look for a cut vertex or an unbalanced bipartition.
  3. Planar? Use V − E + F = 2; for “is it planar?”, test the edge bounds. Equality means maximal planar.
  4. Isomorphic? Compare |V|, |E|, degree sequence and components. If they match, give a mapping and verify every edge and non-edge.
  5. Cut vertex or bridge? Remove it, count components, and compare with the original.
