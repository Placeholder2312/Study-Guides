1 · Functions: definition and vocabulary

Teacher's definition — Module 3 PPT, slide 3

A function f from A to B is defined if for every element a ∈ A there exists a unique element b ∈ B such that f(a) = b, that is (a, b) ∈ f.

A is called the domain of f and B is called the codomain of f. If f(a) = b, then b is the image of a and a is a pre-image of b. The range of f is the set of all images of elements of A. Functions are also called mappings or transformations, and we write f : A → B.

Simple meaning. A function is a machine with one input slot and one output slot. You put in an element of A. You get back exactly one element of B. No input is left without an output, and no input produces two different outputs.

The essential rule — two halves.

  1. Every element of the domain must be used. If some a ∈ A has no image, it is not a function from A to B.
  2. Exactly one image per element. If some a has two images, it is not a function.

Different inputs are allowed to share an output. That is still a function. "Unique output" does not mean "different output".

TermMeaningHow to find it
DomainThe set you start from, AGiven, or the set of all first coordinates
CodomainThe set you are mapping into, BGiven in the question
RangeThe outputs that actually occurCollect all f(a) values; range ⊆ codomain
Image of aThe single value f(a)Substitute a
Pre-image of bEvery a with f(a) = bSolve f(a) = b

Relation versus function. Every function is a relation, but not every relation is a function. A relation becomes a function when each first coordinate appears exactly once and the domain equals A. So a function is a relation with "one output per input".

Testing a set of ordered pairs

  1. List the first coordinates. They must be exactly the elements of A — no missing element.
  2. Check that no first coordinate is repeated with a different second coordinate.
  3. If both checks pass, it is a function. The range is the set of second coordinates that occur.
Worked example — is it a function? (teacher's examples)
Question

Decide whether each relation is a function from A to B. For those that are, give the domain and range.

(a) A = {1, 2, 3}, B = {a, b, c}, f = {(1, a), (2, b), (3, c)}.

(b) A = {1, 2, 3}, B = {a, b, c}, f = {(1, a), (2, b), (3, a)}.

(c) A = {1, 2, 3, 4}, B = {a, b, c}, f = {(1, a), (2, a), (3, b)}.

(d) A = {1, 2, 3}, f = {(1, a), (1, b), (2, c), (3, a)}.

Solution

(a) Every element 1, 2, 3 appears exactly once as a first coordinate, and each has one image. Domain = A = {1, 2, 3}. Range = {a, b, c} = B.

(b) All three inputs appear once. Inputs 1 and 3 share the image a, which is allowed. Range = {a, b}, which is smaller than the codomain.

(c) The first coordinates are {1, 2, 3}, but A = {1, 2, 3, 4}. Element 4 has no image, so the rule "every element of A" fails. This is the teacher's Example on slide 4.

(d) Input 1 has two images, a and b. Each input must have exactly one image.

Final Answer

(a) and (b) are functions — ranges {a, b, c} and {a, b}. (c) and (d) are not functions: 4 has no image, and 1 has two images.

Common mistakes

  • Saying "not a function" just because two inputs share an output. That is allowed.
  • Checking only the repeated first coordinates and forgetting that every element of A must appear.
  • Writing the range as the codomain. The range is only the outputs that actually occur.
  • Confusing the image of a (one value) with the pre-image of b (a set of values).

Quick check 1

A = {1, 2, 3, 4}, B = {p, q, r}. Which of these are functions from A to B? For those that are, give the range.

2 · Injective, surjective, bijective

Teacher's definitions — Module 3 PPT, slides 5, 8, 11, 12

Injective (one-to-one): distinct elements of the domain have distinct images.

f(a1) = f(a2) ⇒ a1 = a2

Surjective (onto): for every b ∈ B there is some a ∈ A with f(a) = b. Every codomain element has at least one pre-image.

Bijective: both injective and surjective — a one-to-one correspondence.

TypeQuestion it answersDisprove it by findingProve it by
InjectiveDo different inputs give different outputs?Two different inputs with the same outputAssuming f(a1) = f(a2) and deriving a1 = a2
SurjectiveDoes every codomain element get hit?One codomain element with no pre-imageTaking arbitrary b ∈ B and producing an a ∈ A with f(a) = b
BijectiveBoth at once?Either failure aboveProving both separately

Quick size check for finite sets. If A and B are finite: injective needs |A| ≤ |B|; surjective needs |A| ≥ |B|; bijective needs |A| = |B|. These are necessary conditions, so a size mismatch is an instant disproof. They do not by themselves prove the property for a particular function.

Worked example 1 — f(x) = x² from Z to Z (teacher's example)
Question

f : Z → Z, f(x) = x².

Find: Is f injective, surjective, bijective? Justify each answer.

Solution

Injective? Test two inputs. f(1) = 1 and f(−1) = 1. Two different inputs give the same output, so f is not injective. One counterexample is enough.

Surjective? Is every integer a square? Take b = 2. There is no integer x with x² = 2, because 1² = 1 and 2² = 4. So 2 has no pre-image and f is not surjective.

Final Answer

f is neither injective nor surjective, so it is not bijective.

Answer-sheet form. "f(1) = f(−1) = 1 with 1 ≠ −1, hence not injective. 2 ∈ Z has no pre-image in Z, hence not surjective. Therefore not bijective."

Worked example 2 — f(x) = x + 1 from Z to Z (teacher's example)
Question

f : Z → Z, f(x) = x + 1.

Find: Prove whether f is injective, surjective and bijective.

Solution

Injective. Suppose f(x) = f(y). Then x + 1 = y + 1, so x = y. Hence f is injective.

Surjective. Let b be any integer in the codomain. Choose x = b − 1. Since b is an integer, b − 1 is an integer and lies in the domain. Then f(b − 1) = (b − 1) + 1 = b. Every codomain element has a pre-image, so f is surjective.

Bijective. Injective and surjective.

Final Answer

f is bijective.

Why both proofs are needed. The injective proof compares two outputs. The surjective proof starts from an arbitrary codomain element and constructs an input. They are different arguments.

Worked example 3 — finite sets and a bijection
Question

A = {a, b, c, d}, B = {1, 2, 3, 4}, f = {(a, 4), (b, 2), (c, 1), (d, 3)}.

Find: Is f bijective?

Solution

The four images are 4, 2, 1, 3 — all different, so f is injective. The range is {1, 2, 3, 4} = B, so f is surjective.

Final Answer

f is bijective. Equivalently: four inputs, four distinct outputs, so the outputs exhaust the four-element codomain.

Common mistakes

  • Proving injectivity by checking one or two values instead of a general argument. One counterexample disproves; a proof needs the general case.
  • Confusing "not injective" with "not a function". They are different failures.
  • Checking surjectivity against the range instead of the codomain. Surjectivity means range = codomain.
  • Forgetting the domain matters: x² is not injective on Z, but it is injective on the non-negative integers.

Quick check 2

Test each for injective, surjective and bijective, with a one-line reason:
(i) f : Z → Z, f(x) = 2x   (ii) g : Z → Z, g(x) = x − 3   (iii) h : R → R, h(x) = x² (Answer Q2.)

3 · Composition of functions

Teacher's definition — Module 3 PPT, slide 14

Let f : A → B and g : B → C be functions. The composition of f and g is denoted g ∘ f : A → C and defined by

(g ∘ f)(a) = g(f(a))

The composition of functions is not commutative: in general f ∘ g ≠ g ∘ f.

How to read the symbol. g ∘ f is read "g after f". The function nearest the input is applied first. In (g ∘ f)(x), you compute f(x) first and then feed that answer into g.

Warning about notation

Your lecture slides use both g ∘ f and gof for the same thing: g applied to the result of f. Some textbooks instead write fg. Always check which order the question uses. The safe rule that never changes: the inside function runs first.

Domain condition. For g ∘ f to make sense, the range of f must lie inside the domain of g. In the definition above, f outputs into B and g accepts B, so the fit is guaranteed. In an exam question with formulas, check this before composing.

Procedure

  1. Identify which function is inside and which is outside.
  2. Substitute the whole inside formula wherever the outside function has its variable.
  3. Expand and simplify.
  4. If asked for both orders, repeat with the roles swapped and compare. Different answers prove non-commutativity.
Worked example — the teacher's pair (slide 15)
Question

f : Z → Z, f(x) = 2x + 3 and g : Z → Z, g(x) = 3x + 2.

Find: (f ∘ g)(x) and (g ∘ f)(x), and compare them.

Solution

(f ∘ g)(x) = f(g(x)). g is inside. Replace x in f by the whole of g(x):

f(3x + 2) = 2(3x + 2) + 3 = 6x + 4 + 3 = 6x + 7.

(g ∘ f)(x) = g(f(x)). f is inside. Replace x in g by f(x):

g(2x + 3) = 3(2x + 3) + 2 = 6x + 9 + 2 = 6x + 11.

Compare. 6x + 7 ≠ 6x + 11, so f ∘ g ≠ g ∘ f.

Final Answer

f ∘ g = 6x + 7 and g ∘ f = 6x + 11; composition is not commutative.

Numerical check. At x = 10: g(10) = 32, then f(32) = 67, matching 6(10) + 7. And f(10) = 23, then g(23) = 71, matching 6(10) + 11. ✓

Verified University question Summer 2026 · Q.2(b) · 7 marks

A shirt costs Rs. 1000. The store gives a 15% discount, then applies 8% sales tax to the discounted price. Develop functions for the discount and the tax, construct the composite function for the final cost, and compute the amount payable.

Question
Solution

Step 1 — define the functions. Let p be the marked price in rupees.

d(p) = p − 0.15p = 0.85p     t(p) = p + 0.08p = 1.08p

d is the "apply 15% discount" function. t is the "add 8% tax" function. Both take a price and return a price.

Step 2 — choose the order. The discount happens first, so the discounted price is the input to tax. Therefore the final cost is t applied to d(p):

(t ∘ d)(p) = t(d(p)) = t(0.85p) = 1.08(0.85p) = 0.918p

Step 3 — compute.

(t ∘ d)(1000) = 0.918 × 1000 = 918

Step 4 — check by hand. Discount: 15% of 1000 = 150, so the discounted price is 850. Tax: 8% of 850 = 68. Final: 850 + 68 = 918. ✓

Step 5 — interpretation. The composite function collapses a two-step billing rule into one formula, 0.918p. The software can compute the final price in one call, the rule is reusable for any marked price, and the order of the steps is recorded in the composition itself.

Honest note about order. Here both steps are pure percentage multiplications, and 0.85 × 1.08 = 1.08 × 0.85, so reversing the order happens to give the same number. The order still matters in the definition — tax is legally computed on the discounted price — and it changes the answer as soon as a step involves a fixed amount. For example, with a flat Rs. 100 discount, t ∘ d gives 1.08(p − 100) = 972 at p = 1000, while d ∘ t gives 1.08p − 100 = 980. Do not claim the two orders always differ; check the actual functions.

Final Answer

(t ∘ d)(p) = 0.918p, so a Rs. 1000 shirt costs Rs. 918.

Common mistakes

  • Applying the outside function first. In (f ∘ g)(x), g runs first.

4 · Inverse functions

Teacher's definition — Module 3 PPT, slides 16–17

Let f : A → B be a bijective function with f(a) = b. The inverse of f is denoted f−1 : B → A and is defined by f−1(b) = a, where a ∈ A and b ∈ B.

If the inverse can be defined, f is invertible. If f is not bijective, an inverse from the full codomain back to the full domain cannot be defined.

For a bijection f : A → B:

(f ∘ f−1)(x) = x for x ∈ B    and    (f−1 ∘ f)(x) = x for x ∈ A

Simple meaning. The inverse undoes the function. If f sends 3 to 7, then f−1 sends 7 back to 3. Every output must be reversible, and no two inputs may share an output — otherwise you would not know which input to return to.

Why bijectivity is required. If f is not injective, two inputs share an output, so the reverse rule cannot decide which one to return. If f is not surjective, some codomain element has no pre-image, so the reverse rule has nothing to return. Injectivity gives a unique answer; surjectivity gives an answer for every codomain element.

Algebraic method

  1. Write y = f(x).
  2. Solve for x in terms of y.
  3. Swap the names x and y to get f−1(x).
  4. Verify with both composition identities.
Worked example — f(x) = 2x + 3, f : R → R (IAT question)
Question

f : R → R, f(x) = 2x + 3.

Find: f−1(x), and verify both composition identities.

Solution

Step 1. y = 2x + 3.

Step 2. y − 3 = 2x, so x = (y − 3)/2.

Step 3. Swap names:

f−1(x) = (x − 3) / 2

Step 4 — verify both identities.

f(f−1(x)) = 2[(x − 3)/2] + 3 = (x − 3) + 3 = x. ✓

f−1(f(x)) = f−1(2x + 3) = [(2x + 3) − 3]/2 = 2x/2 = x. ✓

Final Answer

f−1(x) = (x − 3)/2, and both composition identities hold.

Numerical check. f(5) = 13 and f−1(13) = (13 − 3)/2 = 5. ✓

Answer-sheet form. Write the four steps, then the two composition verifications under headings, then the boxed answer. The verification is usually worth marks.

Worked example — inverse of a finite function (teacher's Example 2.19)
Question

A = {a, b, c}, B = {1, 2, 3}, f = {(a, 1), (b, 3), (c, 2)}.

Find: Is f invertible? If so, write f−1.

Solution

The images are 1, 3, 2 — all different, so f is injective. Every element of B appears, so f is surjective. Hence f is bijective and invertible.

Reverse each pair:

f−1 = {(1, a), (3, b), (2, c)}
Final Answer

f−1 = {(1, a), (2, c), (3, b)}. The domain of f−1 is B and its range is A.

Worked example — when there is no inverse
Question

f : Z → Z, f(x) = x².

Find: Does f−1 : Z → Z exist?

Solution

From Worked example 1, f is neither injective nor surjective. So there is no function f−1 : Z → Z.

Final Answer

No inverse exists on Z. If you restrict the domain to the non-negative integers and the codomain to perfect squares, the same formula becomes bijective and the inverse is the positive square root.

The formula did not change; the domain and codomain did. Always state them.

Common mistakes

  • Writing f−1(x) = 1/f(x). The −1 is inverse-function notation, not a reciprocal.
  • Finding a formula but skipping the verification. Two lines earn marks and catch algebra slips.
  • Forgetting to swap x and y at the end, leaving the answer in terms of y.
  • Claiming an inverse exists for a function that is not bijective.
  • Reversing the pairs but not swapping domain and codomain when describing the inverse.

Q8. f : R → R, f(x) = x³ and g : R → R, g(x) = x1/3. Show that f and g are inverses of each other. (Teacher's slide 19.)

Answer key

Q1

f is a function: all four inputs appear once. Range = {p, q, r}.

g is not a function from A to B, because 4 has no image (the first coordinates are only {1,2,3}).

h is a function: all four inputs appear once. Range = {q, r}.

k is not a function: input 2 has two images, q and r.

Q2

(i) f(x) = 2x on Z. Injective: 2x = 2y ⇒ x = y. Not surjective: 3 ∈ Z has no integer pre-image, since 2x = 3 gives x = 1.5 ∉ Z. Not bijective.

(ii) g(x) = x − 3 on Z. Injective: x − 3 = y − 3 ⇒ x = y. Surjective: for b ∈ Z take x = b + 3 ∈ Z, then g(x) = b. Bijective.

(iii) h(x) = x² on R. Not injective: h(2) = h(−2) = 4. Not surjective onto R: −1 has no real pre-image. Not bijective.

Q3

f(g(x)) = f(2x² + 3) = (2x² + 3) + 1 = 2x² + 4.

g(f(x)) = g(x + 1) = 2(x + 1)² + 3 = 2(x² + 2x + 1) + 3 = 2x² + 4x + 2 + 3 = 2x² + 4x + 5.

They are not equal: 2x² + 4 ≠ 2x² + 4x + 5 (for example at x = 0 the values are 4 and 5). Composition is not commutative.

Q4

(a) y = 5x − 7 ⇒ y + 7 = 5x ⇒ x = (y + 7)/5. So f−1(x) = (x + 7)/5.

Check: f(f−1(x)) = 5[(x + 7)/5] − 7 = (x + 7) − 7 = x. ✓

f−1(f(x)) = [(5x − 7) + 7]/5 = 5x/5 = x. ✓

(b) f−1 = {(4, 1), (5, 2), (6, 3)}.

Q5

A function f : A → B assigns to every a ∈ A exactly one element f(a) ∈ B. The domain is the set A of inputs; the codomain is the set B into which we map; the range is the set of outputs that actually occur, a subset of B.

Example of a relation on {1,2,3} that is not a function: {(1,2), (1,3), (2,1), (3,1)} — input 1 has two images. Also acceptable: {(1,2), (2,3)} — element 3 has no image.

Q6

One-to-one: f(2) = b, f(4) = a, f(6) = d. The three images b, a, d are all different, so distinct inputs have distinct outputs. Hence f is injective.

Onto? No. The codomain is B = {a, b, c, d}, and c has no pre-image. The range is {a, b, d} ≠ B.

Bijective? No, because it is not onto. (It is injective, and |A| = 3 < |B| = 4, so it could not be onto.)

Q7

20% discount: d(p) = 0.80p. 5% tax: t(p) = 1.05p. Final cost = t(d(p)) = 1.05 × 0.80p = 0.84p. At p = 2000: 0.84 × 2000 = Rs. 1680. Check: discount 400, discounted price 1600, tax 80, total 1680. ✓

Flat Rs. 200 discount: d(p) = p − 200, t(p) = 1.05p. Then t(d(p)) = 1.05(p − 200) = 1.05p − 210, giving 2100 − 210 = Rs. 1890 at p = 2000. The reversed order d(t(p)) = 1.05p − 200 gives 1900. The order matters now, because one step is a fixed amount rather than a percentage. Tax must still be applied after the discount.

Q8

(f ∘ g)(x) = f(g(x)) = f(x1/3) = (x1/3)³ = x for all real x.

(g ∘ f)(x) = g(f(x)) = g(x³) = (x³)1/3 = x for all real x.

Both compositions return the identity, so f and g are inverses: g = f−1 and f = g−1.

Q9

y = 3x − 4 ⇒ y + 4 = 3x ⇒ x = (y + 4)/3. So f−1(x) = (x + 4)/3.

Verification: f(f−1(x)) = 3[(x + 4)/3] − 4 = (x + 4) − 4 = x. ✓ And f−1(f(x)) = [(3x − 4) + 4]/3 = 3x/3 = x. ✓

f is a non-constant linear function on R: 3x − 4 = 3y − 4 gives x = y, so it is injective; and for any b ∈ R, x = (b + 4)/3 is real with f(x) = b, so it is surjective. Being bijective, it is invertible.

Last-minute revision sheet

Definitions in one line each

  • Function: every element of A has exactly one image in B.
  • Domain / codomain / range: inputs / target set / outputs that occur.
  • Image / pre-image: f(a) / every a with f(a) = b.
  • Injective: f(a1) = f(a2) ⇒ a1 = a2.
  • Surjective: every b ∈ B has at least one pre-image.
  • Bijective: injective and surjective.
  • Composition: (g ∘ f)(x) = g(f(x)); inside first.
  • Inverse: f−1(b) = a exactly when f(a) = b; exists only for bijections.

Procedures

  • Is it a function? All domain elements used? Each used once? Then yes.
  • Injective? Assume f(a1) = f(a2), derive a1 = a2. Or find two inputs with one output to disprove.
  • Surjective? Take arbitrary b, construct a with f(a) = b. Or find an unhit b to disprove.
  • Compose: substitute the whole inner formula, expand, simplify.
  • Inverse: y = f(x) → solve for x → swap x and y → verify both identities.

Sanity checks

  • Did you state the domain and codomain before testing?
  • Did you give a counterexample for every "not" claim?
  • In composition, did the inside function run first?
  • Did you verify the inverse with both compositions?
  • Is f−1 written with the variable x, not y?

University of Mumbai DSGT (2023112), Module III — Functions, 3 hours, CO3. Prescribed: injective, surjective and bijective functions, composition, inverse functions, real-life applications. Self-learning: neural networks, insurance risk factors, taxes and tax brackets, vending machines.

Questions

  • Summer 2026 Q.2(b) — the discount and tax scenario; the data (Rs. 1000, 15%, 8%) is preserved, and an extra flat-discount variation was added as Q7 for practice.
  • IAT sample — f(x) = 2x + 3 inverse; f = {(1,4),(2,5),(3,7)} one-to-one style question adapted as Q6.
  • Q1–Q5, Q7–Q9 are written for this guide; they are not claimed to be university questions.

Verification performed

  • Compositions checked both algebraically and numerically: at x = 10, f ∘ g = 67 and g ∘ f = 71 for the teacher's pair.
  • The discount/tax computation was checked two ways: 0.918 × 1000 = 918 and 850 + 68 = 918.
  • Both inverse identities were verified symbolically for f(x) = 2x + 3, f(x) = 5x − 7 and f(x) = 3x − 4.
  • The claim that order does not change a two-percentage computation was checked and stated honestly rather than presented as a general rule.

Not covered

Neural-network theory, insurance and taxation case studies, vending machines, advanced abstract function theory, and large sets of composition variations. These are self-learning or extension topics. Deliberate omissions, not oversights.
