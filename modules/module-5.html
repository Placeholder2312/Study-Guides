Section 1 — Introduction to Algebraic Structures

Teacher’s framing: Mrs. Shamal Bagal, Module 5 Algebraic Structures PPT

An algebraic structure is a non-empty set S together with one or more binary operations defined on it. We write it as (S, *) where * is the binary operation.

A binary operation on a set S is a rule that combines any two elements of S to produce another element of S. Mathematically, it is a function *: S × S → S.

Example: Addition on real numbers is a binary operation: +: R × S → R given by (a, b) → a + b.

The Five Core Properties

Teacher’s framing: Properties of Algebraic System

1. Closure property: A binary operation * on a set S is closed if a * b ∈ S for all a, b ∈ S. Every result of the operation must stay inside the set.

Example: Addition is closed on natural numbers because adding two natural numbers always gives a natural number.

Counter-example: Subtraction is not closed on natural numbers because 3 − 5 = −2, which is not a natural number.

Teacher’s framing: Properties of Algebraic System

2. Associative property: A binary operation * is associative if (a * b) * c = a * (b * c) for all a, b, c ∈ S. The grouping of operations does not change the result.

Example: Multiplication on integers is associative: (−2 × 6) × (−5) = −60 and −2 × (6 × −5) = −60.

Counter-example: Subtraction is not associative because (5 − 3) − 2 = 0 but 5 − (3 − 2) = 4.

Teacher’s framing: Properties of Algebraic System

3. Commutative property: A binary operation * is commutative if a * b = b * a for all a, b ∈ S. The order of operands does not matter.

Example: Addition on natural numbers is commutative because 5 + 9 = 9 + 5 = 14.

Teacher’s framing: Properties of Algebraic System

4. Identity element: An element e ∈ S is an identity for operation * if a * e = e * a = a for all a ∈ S. The identity element leaves every element unchanged.

Teacher’s framing: Properties of Algebraic System

5. Inverse element: Let (A, *) be an algebraic system with identity e. An element b is the inverse of a if a * b = b * a = e.

Teacher’s framing: Types of Numbers

Types of numbers used throughout this module:

  • Natural numbers (N): {1, 2, 3, 4, …} — positive numbers only
  • Whole numbers (W): {0, 1, 2, 3, 4, …} — natural numbers plus zero
  • Integers (Z): {…, −3, −2, −1, 0, 1, 2, 3, …} — whole numbers plus negatives
  • Rational numbers (Q): Numbers of the form a/b where a, b ∈ Z and b ≠ 0
  • Real numbers (R): All numbers on the number line, including rationals and irrationals
  • Imaginary/Complex numbers: Numbers involving √−1 = i. Note: The teacher’s PPT uses “imaginary numbers” and “complex numbers” interchangeably. Strictly speaking, imaginary numbers are a subset of complex numbers.

Section 2 — Semigroup

Teacher’s framing: Semi Group

An algebraic system (A, *) is a semigroup if it satisfies two conditions:

  1. * is a closed operation on A.
  2. * is an associative operation on A, i.e., (a * b) * c = a * (b * c) for all a, b, c ∈ A.

A semigroup need not have an identity element or inverses.

Teacher’s Example: Maximum operation on integers

Let Z be the set of integers, and define n * m = maximum of (n, m). Show that (Z, *) is a semigroup.

  • Closure: a * b = maximum of (a, b) is always an integer, so a * b ∈ Z for all a, b ∈ Z.
  • Associativity: (a * b) * c = maximum of {a, b, c} = a * (b * c) for all integers a, b, c.

Therefore, (Z, *) is a semigroup.

Teacher’s Example: Is (Z, *) a monoid?

Is there an identity element x such that a * x = maximum of (a, x) = a for all a ∈ Z?

No. There is no integer x such that maximum of (a, x) = a for all a ∈ Z, because we could always choose a = x − 1, giving maximum of (x − 1, x) = x ≠ x − 1.

Therefore, (Z, *) is not a monoid — it has no identity element.

Section 3 — Monoid

Teacher’s framing: Monoid

An algebraic system (A, *) is a monoid if it satisfies three conditions:

  1. * is a closed operation in A.
  2. * is an associative operation in A.
  3. There is an identity element in A.

A monoid is a semigroup with an identity element. It need not have inverses.

Teacher’s Example: Strings under concatenation

Let S be the set of all strings, and let + denote concatenation. Show that (S, +) is a monoid.

  • Closure: Concatenation of two strings is again a string, so s1 + s2 ∈ S.
  • Associativity: Concatenation is associative: (s1 + s2) + s3 = s1 + (s2 + s3).
  • Identity: The null string λ satisfies s1 + λ = s1 for all strings s1.

Therefore, (S, +) is a monoid.

Is it a group? No. The inverse of a non-empty string does not exist under concatenation (you cannot concatenate anything with "abc" to get the null string "").

Teacher’s Example: Functions from a finite set to itself under composition

Let S be a finite set, and let F(S) be the collection of all functions f: S → S under composition ∘. Show that (F(S), ∘) is a monoid.

  • Closure: Composition of two functions on S is again a function on S, so f1 ∘ f2 ∈ F(S).
  • Associativity: Composition is associative: (f1 ∘ f2) ∘ f3 = f1 ∘ (f2 ∘ f3).
  • Identity: The identity function I: S → S satisfies f1 ∘ I = f1.

Therefore, (F(S), ∘) is a monoid.

Is it a group? No. The inverse of a non-bijective function does not exist.

Section 4 — Groups

Teacher’s framing: Group

An algebraic system (G, *) is a group if it satisfies four conditions:

  1. * is a closed operation.
  2. * is an associative operation.
  3. There is an identity in G.
  4. Every element in G has an inverse in G.

A group is a monoid with inverses. Every element must be able to "undo" itself via the inverse.

Teacher’s Example: Non-zero real numbers under multiplication

Show that R* = set of all non-zero real numbers is a group under multiplication.

  1. Closure: Product of two non-zero real numbers is a non-zero real number, so a · b ∈ R*.
  2. Associativity: Multiplication of real numbers is associative: (a · b) · c = a · (b · c).
  3. Identity: 1 ∈ R* and a · 1 = a for all a ∈ R*.
  4. Inverse: For each a ∈ R*, we have 1/a ∈ R* such that a · (1/a) = 1.

Commutativity also holds (a · b = b · a), so (R*, ·) is an abelian group.

Teacher’s Example: Real numbers under multiplication is NOT a group

0 ∈ R. The multiplicative inverse of 0 does not exist (there is no number x such that 0 · x = 1).

Therefore, (R, ·) is not a group.

Teacher’s Example: Non-singular matrices under multiplication

Let M be the set of all non-singular matrices of order n × n. Show that (M, ·) is a group under matrix multiplication.

  1. Closure: |AB| = |A| · |B| ≠ 0 since A and B are non-singular, so AB ∈ M.
  2. Associativity: Matrix multiplication is associative: (AB)C = A(BC).
  3. Identity: I_n ∈ M and A I_n = A for all A ∈ M.
  4. Inverse: For each A ∈ M, we have A⁻¹ ∈ M such that A A⁻¹ = I.

Matrix multiplication is not commutative, so M is a group but not an abelian group.

Teacher’s Example: Positive rational numbers under a * b = ab/2

Let A be the set of all positive rational numbers. Define a * b = (ab)/2. Show that (A, *) is an abelian group.

  1. Closure: Product of two positive rational numbers is a positive rational number, so a * b ∈ A.
  2. Associativity: (a * b) * c = (ab/2) * c = (abc)/4 and a * (b * c) = a * (bc/2) = (abc)/4.
  3. Identity: Let e be the identity. Then a * e = (ae)/2 = a, so e = 2, and 2 ∈ A.
  4. Inverse: For each a ∈ A, we need a * b = 2. So (ab)/2 = 2, giving b = 4/a, which is in A.
  5. Commutativity: a * b = (ab)/2 = (ba)/2 = b * a.

Therefore, (A, *) is an abelian group with identity 2 and inverse 4/a.

Teacher’s framing: Uniqueness proofs

Theorem: In a group (G, *), the identity element is unique.

Proof: Let e₁ and e₂ be two identity elements. Then e₁ * e₂ = e₁ (since e₂ is identity) and e₁ * e₂ = e₂ (since e₁ is identity). Therefore e₁ = e₂.

Theorem: In a group (G, *), the inverse of any element is unique.

Proof: Let b and c both be inverses of a. Then a * b = e and a * c = e, so a * b = a * c. By left cancellation, b = c.

Theorem: (a * b)⁻¹ = b⁻¹ * a⁻¹ for all a, b ∈ G.

Proof: (a * b) * (b⁻¹ * a⁻¹) = a * (b * b⁻¹) * a⁻¹ = a * e * a⁻¹ = a * a⁻¹ = e. Similarly (b⁻¹ * a⁻¹) * (a * b) = b⁻¹ * (a⁻¹ * a) * b = b⁻¹ * e * b = e. So b⁻¹ * a⁻¹ is an inverse of a * b, and inverses are unique, hence (a * b)⁻¹ = b⁻¹ * a⁻¹.

Theorem: If a * a = a in a group, then a = e (the identity).

Proof: a * a = a * e, so by left cancellation a = e.

Section 5 — Subgroups

Teacher’s framing: Subgroups

Let (G, ⋆) be a group and H be a non-empty subset of G. If (H, ⋆) is itself a group, then H is called a subgroup of G.

A subgroup satisfies all four group laws: closure, associativity, identity element, and inverse law.

Any subset of a group G is called a complex of G (not necessarily a subgroup).

Subgroup example: Even integers under addition

Let 2Z = {…, −4, −2, 0, 2, 4, …} be the set of even integers under addition.

  • Closure: Sum of two even integers is even.
  • Associativity: Integer addition is associative.
  • Identity: 0 ∈ 2Z and a + 0 = a.
  • Inverse: For each a ∈ 2Z, −a ∈ 2Z and a + (−a) = 0.

Therefore, (2Z, +) is a subgroup of (Z, +).

Added for exam use: standard result (not from the teacher’s PPT)

Subgroup test: A non-empty subset H of a group (G, *) is a subgroup if and only if a, b ∈ H ⇒ a * b⁻¹ ∈ H. In additive notation: a, b ∈ H ⇒ a − b ∈ H.

Why it works: Take a ∈ H. Then a * a⁻¹ = e ∈ H. Then e * a⁻¹ = a⁻¹ ∈ H. For a, b ∈ H, b⁻¹ ∈ H, so a * (b⁻¹)⁻¹ = a * b ∈ H. Associativity is inherited from G.

Example: For 2Z in (Z, +): if a, b are even then a − b is even, so 2Z is a subgroup.

Section 6 — Abelian Groups

Teacher’s framing: Abelian group (Commutative group)

A group (G, *) is said to be abelian (or commutative) if a * b = b * a for all a, b ∈ G.

An abelian group satisfies five properties: closure, associativity, identity, inverse, and commutativity.

Section 7 — Cyclic Groups

Source: External reference — Oscar Levin, “Discrete Mathematics: An Open Introduction”

The teacher’s PPT does not cover cyclic groups. This topic is explicitly listed in the official syllabus, so it is included here using an external reference.

A group (G, *) is cyclic if there exists an element g ∈ G such that every element of G can be written as gⁿ (some power of g) for some integer n. The element g is called a generator of the group.

In additive notation, G is cyclic if every element is n·g (some multiple of g) for some integer n.

A cyclic group is generated by a single element. If G = ⟨g⟩, we say G is generated by g.

Finite cyclic groups: If g has finite order m (smallest positive integer such that gᵐ = e), then G = {e, g, g², …, gᵐ⁻¹} and |G| = m.

Example: Z₆ = {0, 1, 2, 3, 4, 5} under addition modulo 6

Is Z₆ cyclic? Yes. Consider the element 1:

  • 1·1 = 1
  • 2·1 = 2
  • 3·1 = 3
  • 4·1 = 4
  • 5·1 = 5
  • 6·1 = 0 (mod 6)

Since multiples of 1 generate all elements of Z₆, 1 is a generator. The element 5 is also a generator (5·1=5, 5·2=4, 5·3=3, 5·4=2, 5·5=1, 5·6=0).

Example: Z₇* = {1, 2, 3, 4, 5, 6} under multiplication modulo 7

Is Z₇* cyclic? Yes. Consider powers of 3 mod 7:

  • 3¹ = 3
  • 3² = 9 ≡ 2
  • 3³ = 27 ≡ 6
  • 3⁴ = 81 ≡ 4
  • 3⁵ = 243 ≡ 5
  • 3⁶ = 729 ≡ 1

All six elements appear, so 3 is a generator. The element 5 is also a generator.

The element 2 is not a generator: 2¹=2, 2²=4, 2³=1, and then it repeats — only {1, 2, 4} are generated.

Cyclic vs non-cyclic groups

A group is cyclic if it has a generator — one element whose powers (or multiples) produce every element of the group.

A group is non-cyclic if no single element generates the entire group. Example: Z₂ × Z₂ (the Klein four-group) is not cyclic because every non-identity element has order 2, so no element generates all 4 elements.

Every cyclic group is abelian, but not every abelian group is cyclic.

Section 8 — Modular Arithmetic and Groups

Teacher’s framing: Modulo systems

Addition modulo m (+ₘ): For positive integer m and integers a, b:

a +ₘ b = a + b    if a + b < m
a +ₘ b = r    if a + b ≥ m, where r is the remainder when a + b is divided by m

Multiplication modulo p (×ₚ): For positive integer p and integers a, b:

a ×ₚ b = ab    if ab < p
a ×ₚ b = r    if ab ≥ p, where r is the remainder when ab is divided by p

Section 9 — Rings

Teacher’s framing: Module 5 ring5.2 PPT

A ring is a set R equipped with two binary operations, usually denoted + (addition) and · (multiplication), such that:

  1. (R, +) is an abelian group.
  2. Multiplication is associative: a · (b · c) = (a · b) · c for all a, b, c ∈ R.
  3. Multiplication distributes over addition: a · (b + c) = a · b + a · c and (a + b) · c = a · c + b · c for all a, b, c ∈ R.

The multiplication operation need not have an identity element. The multiplication operation need not be commutative.

A ring differs from a group in that it has two binary operations instead of one.

Teacher’s framing: Ring properties

A ring must satisfy:

  • Closure under addition and multiplication
  • Associativity of addition and multiplication
  • Distributivity of multiplication over addition
  • Existence of additive identity (0) and additive inverse (−a)

Related Concepts

Teacher’s framing: Commutative rings

A commutative ring is a ring in which multiplication is commutative: a · b = b · a for all a, b ∈ R.

Teacher’s framing: Integral domains

An integral domain is a commutative ring with no zero divisors. If a · b = 0, then either a = 0 or b = 0.

In an integral domain the cancellation law holds: if a · b = a · c and a ≠ 0, then b = c. Example: Z is an integral domain; Z₆ is not, because 2 · 3 = 0 with 2, 3 ≠ 0.

Teacher’s framing: Fields

A field is a commutative ring in which every nonzero element has a multiplicative inverse.

Teacher’s framing: Subrings

A subring is a subset of a ring that is itself a ring under the same operations.

Teacher’s framing: Ring homomorphisms

A ring homomorphism is a function between two rings that preserves addition and multiplication.

Section 10 — Self-Learning: Error Correcting Codes

This is a syllabus self-learning topic. It is not presented as a confirmed exam question.

Error correcting codes are methods for detecting and correcting errors that occur during data transmission or storage.

Connection to algebraic structures: Coding theory uses finite fields (Galois fields) and related algebraic systems. For example, polynomial rings over finite fields are used to construct Reed-Solomon codes, which are used in CDs, DVDs, QR codes, and satellite communications.

Simple example: A parity bit is added to a binary string to make the total number of 1s even (even parity). If a single bit flips during transmission, the receiver detects the error because the parity is wrong. However, it cannot correct the error — only detect it. More sophisticated codes like Hamming codes can both detect and correct errors using parity-check matrices over the field Z₂.

Why it matters: Error correcting codes enable reliable digital communication despite noise in transmission channels.

Answer Key

Answers

Binary Operations and Properties

  1. Addition on N: For any a, b ∈ N, a + b ∈ N. Subtraction on N: Not closed because 3 − 5 = −2 ∉ N.
  2. No. Division by zero is undefined.
  3. Closure: a * b ∈ S for all a, b ∈ S. Example: addition on N. Associativity: (a * b) * c = a * (b * c). Example: multiplication on Z. Commutativity: a * b = b * a. Example: addition on N. Identity: a * e = e * a = a. Example: multiplication on R*, identity = 1. Inverse: a * b = b * a = e. Example: multiplication on R*, inverse of a is 1/a.

Semigroup and Monoid

  1. Semigroup: Closed (max of two integers is integer), associative. Not monoid: No identity element.
  2. Monoid: Closed (concatenation of strings is string), associative, identity = null string. Not group: Non-empty strings have no inverse.
  3. Monoid: Closed (composition of functions is function), associative, identity = identity function. Not necessarily group: Non-bijective functions have no inverse.

Groups

  1. Abelian group: Closed, associative, identity = 1, inverse = 1/a, commutative.
  2. Not a group: 0 ∈ R has no multiplicative inverse.
  3. Group, not abelian: Non-singular matrices form a group under multiplication, but matrix multiplication is not commutative.
  4. Abelian group: Closed, associative, identity = 2, inverse = 4/a, commutative.
  5. Identity unique: If e₁ and e₂ are identities, then e₁*e₂ = e₁ and e₁*e₂ = e₂, so e₁ = e₂.
  6. Inverse unique: If b and c are both inverses of a, then a*b = a*c = e, so b = c by cancellation.

Subgroups and Abelian Groups

  1. Subgroup: Even integers under addition: closed, associative, identity = 0, inverse = −a. All elements of 2Z are in Z, so 2Z is a subgroup of Z.
  2. Abelian: Non-zero real numbers under multiplication. Non-abelian: Non-singular matrices under multiplication.
  3. Difference: An abelian group additionally requires commutativity (a * b = b * a).

Cyclic Groups

  1. Cyclic: Multiples of 1 mod 6 generate all elements {0,1,2,3,4,5}. Generators are 1 and 5.
  2. Cyclic: Powers of 3 mod 7 generate all elements {1,2,3,4,5,6}. Generators are 3 and 5.
  3. No. Example: Z₂ × Z₂ is abelian but not cyclic.

Modular Arithmetic

  1. Group: Addition mod 4 on {0,1,2,3}: closed, associative, identity = 0, inverses = 0→0, 1→3, 2→2, 3→1, commutative. Abelian group.
  2. Inverses in Z₇*: 1→1, 2→4, 3→5, 4→2, 5→3, 6→6.

Rings

  1. Ring: (A,+₁₀) abelian group, (A,·₁₀) semigroup, distributive laws hold.
  2. Ring: (B,+₁₂) abelian group, (B,·₁₂) semigroup, distributive laws hold.
  3. Difference: A field is a commutative ring where every non-zero element has a multiplicative inverse.
  4. Yes, zero divisors: 6 ·₁₂ 6 = 36 ≡ 0 (mod 12), but 6 ≠ 0.

Common Mistakes

Binary Operations

  • Confusing subtraction/division as binary operations on all real numbers — division by zero is undefined.
  • Confusing imaginary numbers with complex numbers — imaginary numbers are a subset of complex numbers.

Semigroup vs Monoid vs Group

  • Forgetting that a monoid needs an identity but a semigroup does not.
  • Forgetting that a group needs inverses but a monoid does not.

Groups

  • Assuming real numbers under multiplication form a group — 0 has no inverse.
  • Assuming all groups are abelian — matrix multiplication is not commutative.

Cyclic Groups

  • Assuming every abelian group is cyclic — Z₂ × Z₂ is abelian but not cyclic.

Modular Arithmetic

  • Important error in teacher’s PPT: Inverses in Z₇* are listed as “1, 4, 5, 2, 5, 6” but the correct inverses are “1, 4, 5, 2, 3, 6”. The inverse of 5 is 3 (5×3=15≡1 mod 7), not 5 (5×5=25≡4 mod 7).

Rings

  • Forgetting that a ring’s multiplication need not have an identity element.
  • Confusing integral domain (no zero divisors) with field (every non-zero element has inverse).

Common Exam Patterns

  • “Show that (S, *) is a semigroup/monoid/group” — check each condition one by one.
  • “Is (S, *) abelian?” — check commutativity.
  • “Is (S, *) cyclic?” — find a generator or show none exists.
  • “Construct composition table for modulo n” — fill all entries, then check closure, identity, inverses, commutativity.
  • “Is (R, +, ·) a ring?” — check (R,+) abelian group, · associative, distributive laws.
