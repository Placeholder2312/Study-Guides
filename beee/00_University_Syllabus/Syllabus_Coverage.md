# BEEE Module I — Syllabus Coverage

**Course:** ESC102 Basic Electrical and Electronics Engineering  
**Program:** B.E. Computer Engineering (AI & ML), Semester I  
**Framework:** NEP 2020, University of Mumbai  
**Teaching Hours:** 10  
**CO:** CO1

## Official Module I Wording
> "DC Circuits: (Only independent sources) Kirchhoff's Laws, Ideal and Practical Voltage and Current Sources, Source Transformation, Mesh and Nodal Analysis (no super node and super mesh) Star-Delta / Delta-Star Transformations, Superposition Theorem, Thevenin's Theorem, Norton's Theorem and Maximum Power Transfer Theorem."

## Topics Covered in This Guide
| Topic | Status | Notes |
|-------|--------|-------|
| Prerequisites (charge, current, voltage, resistance, series/parallel, power/energy) | ✅ | Built from the beginning |
| Ideal and practical voltage/current sources | ✅ | With terminal behaviour |
| Source transformation (V↔I) | ✅ | With rules and limits |
| Kirchhoff's Laws (KCL, KVL) | ✅ | With sign convention table |
| Mesh analysis | ✅ | No supermesh |
| Nodal analysis | ✅ | No supernode |
| Star–delta / delta–star conversion | ✅ | With bridge example |
| Superposition theorem | ✅ | Power non-superposition warning |
| Thevenin's theorem | ✅ | With Norton equivalence |
| Maximum power transfer theorem | ✅ | With efficiency distinction |

## Not Covered (explicitly excluded by syllabus)
- Dependent sources
- Supernodes, supermeshes
- Inductance, capacitance, magnetic circuits (postponed to later modules)
